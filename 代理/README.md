# 代理设置管理工具

## 简介

这是一个用于管理Windows系统代理设置的工具，主要功能是添加代理排除地址（不使用代理的地址列表）。在企业或特定网络环境中，当需要某些内部地址绕过代理服务器直接访问时，此工具可以快速配置系统代理例外列表。

## 功能特点

- **自动获取管理员权限**: 自动请求并获取修改系统代理设置所需的管理员权限
- **智能添加排除地址**: 避免重复添加已存在的地址
- **批量添加**: 支持一次性添加多个排除地址
- **图形界面**: 提供简单的操作界面（通过批处理文件启动）
- **保留现有设置**: 在添加新地址的同时保留原有的代理设置

## 系统要求

- Windows 操作系统
- Python 3.x
- 管理员权限（程序会自动请求）

## 使用方法

### 方法一：使用批处理文件（推荐）

1. 双击运行 `添加代理排除地址.bat`
2. 在弹出的窗口中输入需要排除的地址（多个地址用分号分隔）
3. 确认后，程序会自动添加这些地址到系统代理排除列表

### 方法二：直接运行Python脚本

```bash
# 以管理员身份运行命令提示符，然后执行：
python 添加代理排除地址.py
```

## 常见问题

- **权限不足**: 如果遇到权限问题，请确保以管理员身份运行
- **设置未生效**: 尝试重启浏览器或应用程序，或者重新登录Windows
- **格式错误**: 确保输入的地址格式正确，多个地址之间使用分号(;)分隔

## 注意事项

- 修改系统代理设置可能会影响所有使用系统代理的应用程序
- 建议在添加前先备份当前的代理设置
- 某些应用程序可能使用自己的代理设置而不是系统代理设置
