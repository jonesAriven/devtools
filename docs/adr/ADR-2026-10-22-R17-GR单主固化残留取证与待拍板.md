## 3. 残留一：🔴 全部配置文件 `enforce=ON` 与单主相悖（最尖锐）

- **官方依据**（MySQL 8.0 文档 §20.1.3.1 / §20.9.1）：单主模式下 `group_replication_enforce_update_everywhere_checks` **必须 OFF**；它是**组级配置**，**joiner 值与组不一致将无法入组**（报错形如 `The member configuration is not compatible with the group configuration ... must have the same value on every server in the group`），且运行中不能改、须整组重启才生效。
- **现状**：persist OFF 覆盖配置 ON（persist 优先于 my.cnf），三节点运行时一致 OFF ⇒ 当前健康。
- **爆法**：① 任一节点**数据卷全新初始化**（clone 连 donor 的 persist 一并带走、暂时掩盖；全新 init 直接吃配置 ON）⇒ 无法入组；② 有人按 ADR-2026-10-21 §4「禁用 SET PERSIST 固化」的纪律执行 `RESET PERSIST` ⇒ 拆除后重启即吃配置 ON ⇒ 同样无法入组。**上游 ADR 自带的整改动作，在当前配置文件下会把集群弄坏。**
- **修法（零运行时影响）**：5 个文件（共享 `cluster/node2/node3.cnf` + 182 本地 my.cnf ×2）该行改 `OFF` 或删行（默认 OFF）。只影响未来重启/重建。

## 4. 残留二：🟠 `start_on_boot` 三方不一致，node1 的 T-ENG-14 修复已不在

- T-ENG-14（10-19 07:40）曾把 node1 `start_on_boot` 改 ON（rationale：node1 是所有应用的写入点，重启后不自动入组 = 「孤立但可写」温室，正是 T-ENG-13 分歧事故形态）。
- **现状**：node1 共享 = **OFF**（10-20 12:23 随单主固化重写文件时回退；两份备份显示 07:40 的 ON 在 10-20 12:23 前已不在）；node2/3 本地 = ON；共享 node2/3.cnf（未被使用）= OFF。**最差组合：唯一写入点不自动入组，两个从库自动入组。**
- **权衡**：ON = 崩溃/重启自动重新入组、消除孤立可写岛（T-ENG-14 立场）；OFF = 契合官方 20.5.2 冷启流程（先 bootstrap 再逐个 START；`infra-mysql.md` 明令禁止全量 ON 重启——无引导者会全失败）。补充事实：单主下 node1 不入组时 node2+node3 仍占多数（2/3）可正常选主 + 应用侧 JDBC failover 接管写 ⇒「自动切」不依赖 node1 重入组；但重入组前 node1 是孤立可写岛，JDBC random 仍可能打连接进去写 ⇒ 分歧风险。
- ⚠️ 附带：182 的 `docker-compose.mysql-cluster.debian.yml` **指向共享 node2/3.cnf**，而运行中的 node2/3 挂 182 本地（T-ENG-14「未修」项）⇒ 下次在 182 用该 compose 重建 node2/3，将吃到共享副本的 OFF，行为静默改变。

## 5. 残留三：🟡 node2/3 挂载与共享真源分裂（T-ENG-14 未修项延续）

改共享盘对 node2/3 无效的根因仍在（运行挂 182 本地，共享 node2/3.cnf 无人读），且共享副本与本地副本已不一致（`start_on_boot`：共享 OFF vs 本地 ON；`enforce`：双方都 ON 且相悖）。

## 6. 待拍板（T-DEC-5 四项，按依赖排序）

| # | 动作 | 风险 | 依赖 |
|---|---|---|---|
| 1 | **`enforce=ON` → OFF**（5 个配置文件，可删行） | **零运行时影响**（persist 已压成 OFF；只影响未来重启/重建） | 无，**优先** |
| 2 | **node1 `start_on_boot` 定口径**（恢复 ON / 维持 OFF）并统一三节点（本地 + 共享副本） | 改配置不动运行时；ON/OFF 是真实权衡（§4） | 良哥选边 |
| 3 | **node2/3 挂载对齐**：A = 182 改挂共享 node2/3.cnf / B = 明确本地为真源、处理共享副本 | A 涉及 182 容器重建（SECONDARY，读瞬断、写不受影响）；B 纯文档/文件处置 | 依赖 2 的值先定 |
