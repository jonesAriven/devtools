# 🎨 画图工具选择指南

> 下次要画图时，先看这个，选好工具再动手

## 工具对比

| 工具 | 适合场景 | 优点 | 缺点 |
|------|---------|------|------|
| **Mermaid 文本** | 简单流程图、架构图<br>（节点少、连线简单） | 纯文本，改起来快<br>可以代码版本管理<br>一键渲染 PNG/SVG | 自动布局，复杂拓扑线条乱<br>无法精确控制位置<br>节点一多就绕线 |
| **手写 SVG** | 复杂拓扑图<br>（需要精确定位） | 完全可控，想怎么画就怎么画<br>矢量渲染，无限清晰<br>可以标任意细节 | 改起来麻烦，坐标手动算<br>比较费时 |
| **Draw.io** | 专业网络拓扑图<br>（拖拽画图） | 专业工具，拖拽即可<br>模板多、形状库丰富<br>支持图层/分组/精确对齐 | 需要手动拖拽<br>通过我操作比较困难<br>最好你画我帮你标 |
| **Excalidraw** | 手绘风格草图 | 简单易用<br>手绘风格好看<br>支持协作 | 不如 draw.io 专业 |

## 常用命令

```bash
# Mermaid → PNG 渲染
mmdc -i 文件.mmd -o 输出.png -b white --scale 3

# Mermaid → SVG 渲染（矢量）
mmdc -i 文件.mmd -o 输出.svg -b white

# SVG → 高清 PNG（librsvg）
rsvg-convert --background-color=white --width=5400 --height=3300 -o 输出.png 输入.svg
```
