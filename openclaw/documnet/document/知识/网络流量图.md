# 网络流量图（文本版）

## 出网链路（内→外）

```
内网 Debian → Clash(:7890) → 龙虾 Shadowsocks(:8388) → 公网
阿里云     → Clash(:7890) → 龙虾 Shadowsocks(:8388) → 公网
腾讯云2号  → Clash(:7890) → 龙虾 Shadowsocks(:8388) → 公网
内网 Debian → 家庭宽带直连 → 国内网站
阿里云     → 公网直连 → 国内网站
腾讯云2号  → 公网直连 → 国内网站
mykng-debain → 家庭宽带直连 → 国内网站
```

## 入网链路（外→内）

```
用户 → tools.marschat.online
  → 腾讯云2号 Nginx(:443)
  → 阿里云 FRP 服务端(:18080/18085)
  → FRP 隧道
  → 内网 Debian (DS/激活码) / mykng-debain (知识库)
```
