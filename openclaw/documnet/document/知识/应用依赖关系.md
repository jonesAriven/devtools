# 应用依赖关系

## 核心依赖

### 访问链路

```
用户 HTTPS
  ↓ (DNS: 腾讯云2号)
Nginx 反代 (:443)
  ↓
[反向代理目标]
  ├── aliyun.marschat.online:8081 (Nexus)
  ├── aliyun.marschat.online:18080 (激活码正式)
  ├── aliyun.marschat.online:18081 (激活码测试)
  ├── mykng-debain:8080 (知识库)
  └── 内网 Debian:12346 (DolphinScheduler)
```

### FRP 隧道依赖

```
阿里云 FRP 服务端 (:7000)
  ├── FRP 隧道 → 内网 Debian
  │     ├── SSH(3383) → MySQL :3306 → HiveServer2 :10000
  │     └── DolphinScheduler :12346 → Hive
  ├── FRP 隧道 → 内网旧 Windows
  │     ├── RDP(3381) → :3389
  │     └── SSH(3382) → :22
  ├── FRP 隧道 → 内网新 Windows :18081 (激活码测试)
  └── FRP 隧道 → mykng-debain
        ├── SSH(3385) → :22
        └── 知识库(18085) → :8080 (已挂❌)
```

### 代理依赖

```
Clash 客户端各节点
  └── 上游 → 龙虾主机 Shadowsocks :8388 (aes-256-gcm)
```

## 详细依赖
- DS → HiveServer2 (JDBC :10000)
- DS → MySQL (元数据存储)
- 激活码 → MySQL (业务数据)
- 知识库 → MySQL (kb/kb123456 @ kb-mysql:3306/knowledge_base)
- 知识库 → MongoDB (kb-mongo:27017)
- 知识库 → MinIO (minioadmin/minioadmin @ kb-minio:9000)
- 知识库 → MeiliSearch (masterKey @ kb-meilisearch:7700)
- 腾讯云2号 Nginx → 阿里云 FRP (反代内网服务)
- 阿里云 Clash → 龙虾 Shadowsocks (代理出口)
- 内网 Debian Clash → 龙虾 Shadowsocks (代理出口)
- 腾讯云2号 Clash → 龙虾 Shadowsocks (代理出口)
