## 概述

基于现有 Nexus Repository Manager（腾讯云2号，1.117.70.30）搭建 Maven、npm 和 PyPI 三大语言私服，统一管理对外代理和私有包发布。

**部署架构：** 每种语言按「国内镜像代理 + 官方源代理 + 本地仓库」三层结构，通过 group 仓库合并对外暴露。

## 代理配置

### 出网代理

Nexus 通过 JVM 参数配置 HTTP 代理，指向腾讯云2号本机的 Clash Meta（127.0.0.1:7890）：

```bash
-Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=7890
```

### Clash 代理规则

Clash 规则已配好对应域名的代理/直连策略（配置文件 `/etc/clash/config.yaml`）：

| 域名 | 策略 | 说明 |
|------|------|------|
| `pypi.org`、`python.org` | → Proxy（龙虾-SS） | PyPI 官方源走代理出国 |
| `registry.npmjs.org` | → Proxy（龙虾-SS） | npm 官方源走代理出国 |
| `repo1.maven.org` | → Proxy（龙虾-SS） | Maven Central 走代理出国 |
| `mirrors.aliyun.com`、`pypi.tuna.tsinghua.edu.cn` | → DIRECT | 国内镜像直连 |
| `registry.npmmirror.com` | → DIRECT | 国内镜像直连 |

## 仓库结构

### Maven

| 仓库名 | 类型 | 上游源 | 代理策略 |
|--------|------|--------|---------|
| `maven-central` | proxy | `https://repo1.maven.org/maven2/` | 走 Clash 出国 |
| `aliyun-maven` | proxy | `https://maven.aliyun.com/repository/public` | 直连 |
| `huaweiyun` | proxy | `https://repo.huaweicloud.com/repository/maven/` | 直连 |
| `maven-releases` | hosted | — | 本地发布（正式版） |
| `maven-snapshots` | hosted | — | 本地发布（快照版） |
| **`maven-public`** | **group** | maven-central + releases + snapshots | 官方源优先 |
| **`all-group`** | **group** | maven-public + aliyun + huaweiyun | 国内镜像优先 |

**使用方式（settings.xml）：**
```xml
<mirror>
  <id>nexus</id>
  <mirrorOf>*</mirrorOf>
  <url>https://nexus.marschat.online/repository/all-group/</url>
</mirror>
```

### npm

| 仓库名 | 类型 | 上游源 | 代理策略 |
|--------|------|--------|---------|
| `npm-proxy` | proxy | `https://registry.npmjs.org` | 走 Clash 出国 |
| `npm-taobao` | proxy | `https://registry.npmmirror.com` | 直连（国内镜像） |
| `npm-hosted` | hosted | — | 本地发布 |
| **`npm-public`** | **group** | npm-taobao → npm-proxy → npm-hosted | 国内镜像优先 |

**使用方式：**
```bash
# 全局配置
npm config set registry https://nexus.marschat.online/repository/npm-public/

# 发布私有包
npm publish --registry https://nexus.marschat.online/repository/npm-hosted/
```

### PyPI

| 仓库名 | 类型 | 上游源 | 代理策略 |
|--------|------|--------|---------|
| `pypi-proxy` | proxy | `https://pypi.org` | 走 Clash 出国 |
| `pypi-aliyun` | proxy | `https://mirrors.aliyun.com/pypi` | 直连（国内镜像） |
| `pypi-tsinghua` | proxy | `https://pypi.tuna.tsinghua.edu.cn` | 直连（国内镜像） |
| `pypi-hosted` | hosted | — | 本地发布 |
| **`pypi-public`** | **group** | pypi-aliyun → pypi-tsinghua → pypi-proxy → pypi-hosted | 国内镜像优先 |

**使用方式：**
```bash
# 全局配置
pip config set global.index-url https://nexus.marschat.online/repository/pypi-public/simple/

# 发布私有包（需配 ~/.pypirc）
twine upload --repository-url https://nexus.marschat.online/repository/pypi-hosted/ dist/*
```

## 部署维护

### 启动/停止
```bash
systemctl start nexus
systemctl stop nexus
systemctl restart nexus
```

### 查看日志
```bash
tail -f /software/devTools/nexus/sonatype-work/nexus3/log/nexus.log
```

### 数据备份
Nexus 数据在 `/software/devTools/nexus/sonatype-work/nexus3/`，特别是：
- `db/nexus.mv.db` — H2 数据库（仓库配置）
- `blobs/` — 包缓存和本地发布内容

### 新增国内镜像
参考现有结构，通过 Nexus 管理界面或 REST API 新增 proxy 仓库，然后加到 group 成员中。

REST API 方式（ExtDirect）：
```bash
# 读取所有仓库
curl -s -u admin:Hwx@1120930 -X POST "http://127.0.0.1:8081/service/extdirect" \
  -H "Content-Type: application/json" \
  -d '{"action":"coreui_Repository","method":"read","data":[],"type":"rpc","tid":1}'

# 更新 group 仓库成员
curl -s -u admin:Hwx@1120930 -X POST "http://127.0.0.1:8081/service/extdirect" \
  -H "Content-Type: application/json" \
  -d '{"action":"coreui_Repository","method":"update","data":[{"name":"仓库名","type":"group","format":"格式","recipe":"格式-group","online":true,"attributes":{"storage":{"strictContentTypeValidation":true,"dataStoreName":"nexus","blobStoreName":"default"},"group":{"memberNames":["成员1","成员2",...]}}}],"type":"rpc","tid":1}'
```
