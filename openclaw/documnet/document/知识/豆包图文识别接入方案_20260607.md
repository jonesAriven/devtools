> 日期：2026-06-07
> 状态：✅ 已部署运行

## 概述

通过 MCP (Model Context Protocol) 将火山引擎 ARK 的 Doubao Vision 视觉理解能力接入 OpenClaw，让 AI 能"看懂"图片内容。

**应用场景：** 用户发图片 → mcporter 调用 MCP Server → 调豆包视觉理解 API → 返回图片描述

## 接入步骤（通用模板）

这套方案适用于**所有基于 HTTP API 的大模型能力**接入。替换为其他模型/服务时，只需要改第②步中的 API 地址、模型名和参数。

#### 本方案实例（豆包视觉理解）

脚本位置：`/opt/doubao-vision-mcp/mcp_server.py`

核心代码：

```python
@mcp.tool()
def vision_understand(image_url: str, prompt: str = "请详细描述这张图片的内容") -> str:
    """豆包视觉理解"""
    payload = {
        "model": ENDPOINT_ID,
        "messages": [
            {
                "role": "user",
                "content": [
                    {"type": "image_url", "image_url": {"url": image_url, "detail": "auto"}},
                    {"type": "text", "text": prompt}
                ]
            }
        ],
        "max_tokens": 2000
    }
    resp = requests.post(API_URL, headers=headers, json=payload, timeout=60)
    data = resp.json()
    return data["choices"][0]["message"]["content"]
```

### ③ 配置 mcporter

编辑 `/root/.mcporter/mcporter.json`，新增一个 stdio 模式的 MCP Server：

```json

    "你的服务名": {
      "command": "python3",
```

## 关键技术要点

### 关于 mcporter 的 transport 模式

| 模式 | 适用场景 | 配置方式 |
|------|---------|---------|
| **stdio** | ✅ 本机运行的 Python/Node.js MCP Server | `command` + `args` + `env` |
| **HTTP/SSE** | ❌ 外部 HTTP 服务 | `url`/`baseUrl` + `headers` |

> ⚠️ mcporter 的 HTTP 模式要求服务端支持 **SSE (Server-Sent Events)** 协议，普通 REST API 不兼容。所以本地运行的 MCP Server **必须用 stdio 模式**。

### 图片 URL 可达性

ARK API 需要**能直接访问**图片 URL。如果你的图片在内网或服务器本地，需要：

1. 复制图片到 Nginx 静态目录（如 `/home/www/html/`）
2. 通过公网域名或 IP 访问（如 `http://你的公网IP/test-vision.jpg`）
3. 或者用 base64 编码直接传数据（需改代码）

### 环境变量安全

API Key 通过 mcporter 配置的 `env` 字段传入，不要在脚本中硬编码。mcporter 的配置 `mcporter.json` 需要保护好权限：

```bash
chmod 600 /root/.mcporter/mcporter.json
```

## 如果要接入其他模型/服务

参考这个模板四步走：

1. **装依赖** — `pip3 install mcp requests`
2. **写脚本** — 用 FastMCP 封装一个工具函数，调目标 API
3. **配 mcporter** — 在 `mcporter.json` 加一条 stdio 配置
4. **验证** — `mcporter list` + `mcporter call`

关键就是第二步的 Python 脚本，其他都是套路。
