# Hive 定时任务：每天凌晨1点删除 temp_ 临时表

## 基本信息
- **创建时间：** 2026-06-02
- **创建人：** 良哥要求
- **所属库：** csap、csap270
- **执行时机：** 每天 01:00

## 实现方式
- **调度引擎：** Linux crontab（root01 用户）
- **执行脚本：** 通过 Shell 脚本调用 `docker exec hive-server2 beeline` 执行 Hive DDL
- **存储位置：** 内网 Debian 主机（192.168.31.182）

## 配置详情

| 项目 | 值 |
|------|-----|
| 脚本路径 | `/home/root01/drop_temp_tables.sh` |
| 日志路径 | `/home/root01/drop_temp_tables.log` |
| 定时表达式 | `0 1 * * *` |
| 清理范围 | `csap`、`csap270` 两个库 |
| 匹配规则 | `temp_` 开头的表名 |

## 管理命令

```bash
# 查看定时任务（SSH 到内网 Debian 后）
crontab -l

# 查看执行日志
tail -f /home/root01/drop_temp_tables.log

# 手动触发一次
bash /home/root01/drop_temp_tables.sh
```

## 后续维护提示
- 如果新增了其他需要清理 temp 表的 Hive 库，需要同步更新脚本和 crontab
- 如果要改执行时间，直接 `crontab -e` 编辑即可
