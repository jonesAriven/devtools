## 二、问题排查记录

### 2.1 知识库 API 返回 403

**现象：** 所有 API 请求返回 403 Forbidden

**排查过程：**
1. 检查 Nginx 配置 → 正确
2. 检查 Tailscale 连接 → mykng-debain 离线
3. 重启 Tailscale 服务 → 连接恢复
4. API 正常返回数据

**根本原因：** mykng-debain 的 Tailscale 服务停止运行，导致腾讯云2号无法通过 Tailscale 访问

**解决方案：** 
```bash
sshpass -p root ssh root@100.93.36.113 "systemctl restart tailscaled && tailscale up"
```

### 2.2 知识库登录失败

**现象：** 使用 admin/admin123 登录返回"用户名或密码错误"

**排查过程：**
1. 检查数据库用户表 → admin 用户存在
2. 检查密码哈希 → 与 admin123 的 BCrypt 哈希不匹配
3. 更新密码哈希 → 登录成功

**根本原因：** 数据库中的密码哈希与 admin123 不匹配（可能是初始化时使用了不同的密码）

**解决方案：**
```sql
-- 生成正确的 BCrypt 哈希
-- admin123 → $2b$10$zgCtn4bdqCN6ltv38WdyUuJkers7A3XZrd0.baZUK1LtJ5Air0aEu

UPDATE user 
SET password='$2b$10$zgCtn4bdqCN6ltv38WdyUuJkers7A3XZrd0.baZUK1LtJ5Air0aEu' 
WHERE username='admin';
```

## 三、FRP 隧道配置详情

```toml
[common]
server_addr = "100.89.102.74"
server_port = 7000
token = "YourStrongToken!"

[http-kb]
type = "tcp"
local_ip = "127.0.0.1"
local_port = 8080
```

### 3.3 访问链路

```

```
