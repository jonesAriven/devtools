
## 3.9 关键文件路径

### 内网 Debian — Hive Compose 项目（~/hive-compose/）

| 文件 | 用途 |
|------|------|
| `docker-compose.yml` | 编排文件 |
| `conf/hive-site.xml` | Metastore 配置（含 MySQL JDBC） |
| `conf-hs2/hive-site.xml` | HS2 配置（仅 Metastore URI） |
| `jars/mysql-connector-j-9.2.0.jar` | MySQL JDBC 驱动 |

### 内网 Debian — 系统配置

| 路径 | 用途 |
|------|------|
| `/etc/docker/daemon.json` | Docker 镜像加速 |
| `/etc/frp/frpc.toml` | FRP 客户端配置 |
| `/etc/proxychains4.conf` | SOCKS5 代理配置 |
| `/etc/systemd/system/autossh-socks.service` | SOCKS5 隧道服务 |

### 阿里云

| 路径 | 用途 |
|------|------|
| `/etc/frp/frps.ini` | FRP 服务端配置 |

### 龙虾主机

| 路径 | 用途 |
|------|------|
| `/home/www/html/hive-4.2.0.tar.gz` | Hive 镜像文件 |
