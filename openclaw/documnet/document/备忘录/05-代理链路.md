### 代理规则

| 域名 | 走代理 | 说明 |
|------|--------|------|
| google.com | ✅ Proxy | 国外网站 |
| youtube.com | ✅ Proxy | 国外网站 |
| github.com | ✅ Proxy | GitHub 资源下载 |
| docker.com | ✅ Proxy | Docker Hub 镜像拉取 |
| pypi.org / python.org | ✅ Proxy | PyPI 海外源 |
| cloudflare.com | ✅ Proxy | 部分 CDN 资源 |
| 其他国内域名 | ❌ DIRECT | 直连 |

### 注意

- **国内网站不走代理，更不会绕阿里云中转** — 内网 Debian 访问国内网站直接走家庭宽带直连（快），Clash 的 `GEOIP,CN,DIRECT` 规则自动处理。绕阿里云只会更慢（阿里云带宽 3-5Mbps 远低于家庭宽带）
- 代理仅用于**被墙的国外网站**（Google、Docker Hub、GitHub Releases 等）
- 阿里云 DNS 未开启 Clash DNS（无污染问题），内网 Debian 开启了 Clash DNS 以解决 DNS 污染
- 内网 Debian 的 Clash hosts 配置了 `host.docker.internal → 192.168.31.182`，供 activecode 容器连接 MySQL
- Clash 二进制路径：`/usr/local/bin/clash-meta`
- 日志查看：`journalctl -u clash-meta -n 50`
