
## 3.10 快速运维命令

### 🎯 各机器标准操作路径（优先参考！不要现想！）

| 目标 | 推荐方式 | 标准命令 |
|------|---------|---------|
| 🦐 龙虾主机（当前） | 本地执行 | — |
| ☁️ 阿里云 | 龙虾→公网直连 | `sshpass -p Hwx@1120930 ssh root@120.26.66.182` |
| ☁️ 腾讯云2号 | 龙虾→公网直连 | `sshpass -p Hwx@1120930 ssh root@1.117.70.30` |
| 📦 内网 Debian | ⭐ **阿里云中转（推荐）** | `sshpass -p Hwx@1120930 ssh root@120.26.66.182 "sshpass -p root01 ssh -p 3383 root01@127.0.0.1 命令"` |
| 📦 内网 Debian（sudo提权） | 阿里云中转 | `sshpass -p Hwx@1120930 ssh root@120.26.66.182 "sshpass -p root01 ssh -p 3383 -o RequestTTY=no root01@127.0.0.1 'echo root01 | sudo -S 命令'"` |
| 📦 内网 Debian（备选） | 直连frp端口 | `sshpass -p root01 ssh -p 3383 root01@120.26.66.182`
| 🖥️ mykng-debain（FRP隧道3385） | 阿里云中转 | `sshpass -p Hwx@1120930 ssh root@120.26.66.182 "sshpass -p root01 ssh -p 3383 root01@127.0.0.1 sshpass -p root ssh root@192.168.31.105 命令"`
| 🖥️ mykng-debain（直连FRP） | 直连frp端口 | `sshpass -p root ssh -p 3385 root@120.26.66.182`
| 🖥️ mykng-debain（Tailscale） | Tailscale 直连 | `ssh root@100.93.36.113`

> 每个sudo命令用 `echo root01 | sudo -S` 模式传入密码

```bash
# === SSH 连接 ===
# 连接内网 Debian（通过阿里云 FRP 隧道）
sshpass -p 'root01' ssh -p3383 root01@120.26.66.182
# 或简写（已配置到 known_hosts）
sshpass -p 'root01' ssh -o StrictHostKeyChecking=no -p 3383 root01@127.0.0.1  # 在阿里云上执行

# === Hive 管理 ===
cd ~/hive-compose && docker compose up -d     # 启动
docker compose down                            # 停止（保留数据）
docker compose down -v                         # ⚠️ 销毁数据！
docker logs -f hive-server2                   # 查看 HS2 日志

# === MySQL 管理 ===
docker exec -it hive-mysql mysql -u root -pHwx@1120930

# === FRP 管理 ===
sshpass -p 'Hwx@1120930' ssh root@120.26.66.182 "systemctl restart frps"
systemctl restart frpc

# === Nexus 管理 ===
sshpass -p 'Hwx@1120930' ssh root@120.26.66.182 "systemctl restart nexus"

# === ~~火山云 pip 私服管理（已下线）~~ ===
# PyPI 已统一到 Nexus，无需管理火山云

# === Registry 隧道 ===
# Docker Registry SSH 隧道已废弃（镜像改用 Nexus Docker 私服）

# === Clash 代理管理 ===
# 内网 Debian
ssh -p3383 root01@120.26.66.182 "systemctl restart clash-meta"
curl -x http://127.0.0.1:7890 https://www.google.com -o /dev/null -w '%{http_code}'

# 阿里云
sshpass -p 'Hwx@1120930' ssh root@120.26.66.182 "systemctl restart clash-meta"
curl -x http://127.0.0.1:7890 https://www.google.com -o /dev/null -w '%{http_code}'

# === Tailscale 管理 ===
tailscale status                          # 查看所有在线设备
tailscale ip -4                           # 查看本机 Tailscale IP
tailscale up                              # 首次登录（浏览器访问打印的链接）

# === SMB 共享目录管理（Windows 服务端）===
# 挂载 SMB 共享（新客户端）
# 云机器（通过 Tailscale）：
mount -t cifs //100.70.76.54/ideaworkspace /mnt/shared \
  -o username=share,password=share123,vers=3.0

# 家庭内网机器（局域网直连）：
mount -t cifs //192.168.31.77/ideaworkspace /mnt/shared \
  -o username=share,password=share123,vers=3.0

# 卸载
umount /mnt/shared

# === 端口验证 ===
ss -tlnp | grep -E "3306|10000|9083|12346"
