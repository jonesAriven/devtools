# SMB共享目录踩坑记录（2026-06-11）

## 背景
- 共享目录服务端：新 Windows（192.168.31.77），用户 share/share123
- 需要挂载 `//192.168.31.77/ideaworkspace` 到龙虾主机的 `/mnt/shared`

## 踩坑记录

### 坑1：mount 时不指定 SMB 版本
**错误做法：** 手动 `mount -t cifs //100.70.76.54/ideaworkspace /mnt/shared` 不带 vers 参数
**表现：** SMB 版本协商失败，连接卡死
**正确做法：**
```
mount -t cifs //100.70.76.54/ideaworkspace /mnt/shared -o username=share,password=***,vers=3.0
```
**备注：** fstab 里已有 `vers=3.0`，用 `mount /mnt/shared` 即可，不要自己写 mount 命令

### 坑2：大文件 cp 到共享目录时中断导致 cifs 卡死
**错误做法：** 在龙虾上用 `cp /home/www/html/debian-preseed.iso /mnt/shared/temp/`（941MB）
**表现：** SMB 写大文件时速度慢（SMB2.0），中途 ctrl+c 或超时后，mount.cifs 进程进入 D 状态（不可中断睡眠），无法 kill
**正确做法：** 小文件直接 cp，大文件：
  - 让目标机器（旧Windows）通过共享目录直接拉，不要通过龙虾中转
  - 或者直接用 `cmd /c` 在旧Windows SSH 里一次性挂载+复制

### 坑3：重复 mount 不先 umount
**错误做法：** 发现挂不上就一直重试 `mount -t cifs ...`，产生多个 D 状态的 mount.cifs 进程
**表现：** 累积了 6 个卡死的 mount.cifs 进程，D 状态 kill -9 也杀不掉
**正确做法：** 每次 mount 前先 `umount -l /mnt/shared` 确保已卸载，最多等15秒，不行就放弃

### 坑4：使用 Tailscale IP 而非局域网 IP
两个都能用，但：
- Tailscale IP `100.70.76.54`：走虚拟网络，延迟 200ms
- 局域网 IP `192.168.31.77`：走局域网，延迟 <1ms
**优先使用局域网 IP**

### 坑5：旧 Windows SSH 下访问共享目录不用 cmd /c 会丢失挂载
**错误做法：**
```
net use Z: \\192.168.31.77\ideaworkspace /user:share share123
dir Z:\temp
```
两条命令分开执行，第二次 SSH session 里 Z: 盘没了
**正确做法：**
```
cmd /c "net use Z: \\192.168.31.77\ideaworkspace /user:share share123 >nul 2>&1 & dir Z:\temp"
```
一次性在 cmd /c 里完成挂载和操作

### 坑6：旧Windows SMB 访问新Windows 被拒绝时没加凭据
**表现：** `dir \\192.168.31.77\ideaworkspace` 报"登录失败：未知用户名或密码错误"
**原因：** SSH 用 administrator 账户执行，没有新 Windows 的 SMB 凭据
**正确做法：**
```
cmd /c "net use Z: \\192.168.31.77\ideaworkspace /user:share share123 >nul 2>&1 & dir Z:\temp"
```

## 正确的挂载方法

### 龙虾主机挂载共享目录
```bash
# fstab 已有配置，只需：
mount /mnt/shared

# 如果 fstab 没有，用：
mount -t cifs //100.70.76.54/ideaworkspace /mnt/shared -o username=share,password=share***,vers=3.0,_netdev

# 注意：vers=3.0 必须指定，否则可能协商失败
```

### 旧 Windows SSH 访问共享目录
```batch
cmd /c "net use Z: \\192.168.31.77\ideaworkspace /user:share share123 >nul 2>&1 & 命令"
```

### 从共享目录复制文件到旧 Windows（已验证成功）
```batch
cmd /c "net use Z: \\192.168.31.77\ideaworkspace /user:share share123 >nul 2>&1 & copy Z:\temp\文件 D:\huliang\文件"
```

## 恢复方法
如果 mount.cifs 卡死（D 状态进程），只能重启龙虾主机。
```bash
systemctl restart openclaw  # 先记录重启后如何启动
reboot
# 重启后：
mount /mnt/shared
```
