## 一、整体架构

```
用户（公网）
    │ HTTPS
    ▼
┌─────────────────────────────┐
│  腾讯云2号 Nginx (:443)      │
│  tools.marschat.online      │
│  → 反代到旧 Windows         │
└──────────┬──────────────────┘
           │ Tailscale / 家庭宽带
           ▼
┌─────────────────────────────┐
│  旧 Windows 宿主机           │
│  ┌───────────────────────┐  │
│  │ VirtualBox 虚拟机      │  │
│  │ Linux Server (Docker) │  │
│  │  ├─ 业务后端(SpringBoot)│  │
│  │  ├─ MySQL 8.0          │  │
│  │  ├─ Redis              │  │
│  │  ├─ MinIO              │  │
│  │  └─ MeiliSearch        │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

**数据流向：** 外网用户 → 腾讯云2号 Nginx（SSL终结）→ 家庭宽带 → 旧 Windows → VirtualBox Linux 虚拟机 → Docker 容器

## 四、网络互通方案

### 4.1 访问链路

```
[用户] → HTTPS → [腾讯云2号 Nginx] → 家庭宽带 → [旧Windows 192.168.31.243]
                                                          → [虚拟机的桥接IP]
```

**三种互通方式（选一种即可）：**

| 方式 | 说明 | 推荐度 |
|------|------|--------|
| **方式A：Tailscale** | 旧Windows装Tailscale客户端，虚拟机和腾讯云2号在一个虚拟子网 | ⭐ 推荐 |
| 方式B：Nginx反代+宿主机端口转发 | 腾讯云2号直接反代旧Windows公网IP+端口 | 备选 |
| 方式C：FRP隧道 | 复用现有FRP隧道，旧Windows跑frpc暴露端口 | 备选 |

**推荐方式A：** 旧 Windows 装 Tailscale（我们已经有了账号，新 Windows 已装了），虚拟机桥接模式下走宿主机网络，跟腾讯云2号、阿里云等 Tailscale 成员直连。

### 4.2 端口规划

| 端口 | 服务 | 说明 |
|------|------|------|
| 8080 | SpringBoot API | 后端业务接口 |
| 3306 | MySQL | 数据库（仅内网访问） |
| 6379 | Redis | 缓存（仅内网访问） |
| 9000 | MinIO API | 对象存储接口 |
| 7700 | MeiliSearch | 检索引擎 |

腾讯云2号 Nginx 只需要暴露 SpringBoot 的 8080 端口（通过 `/api/v1/` 反代），其他组件不对外暴露。

## 五、部署步骤（概要）

### 阶段一：建虚拟机
1. VirtualBox 创建 Linux 虚拟机（4核8G、100GB磁盘、桥接网络）
2. 安装 Docker CE + docker-compose
3. 安装 Tailscale 客户端
4. 配置虚拟机固定局域网 IP

### 阶段二：启动中间件
1. 编写 `docker-compose-lite.yml`（MySQL + MongoDB + Redis + MinIO + MeiliSearch）
2. 启动并验证各组件
3. MinIO 挂载 E 盘作为数据目录（大容量存储）

### 阶段三：部署业务应用
1. 从共享目录 `/mnt/shared/devtools/mykng/` 拉取源码
2. 编译 SpringBoot JAR
3. Docker 化运行，配置连接中间件

### 阶段四：配置 Nginx 反代
1. 腾讯云2号 Nginx 新增 location 反代到旧 Windows
2. 配置 SSL（复用 tools.marschat.online 的 SSL）
3. 配置 SPA 前端路由 fallback

## 六、与腾讯云2号 Nginx 的集成

在腾讯云2号的 `tools.marschat.online` 配置上新增：

```
location /kb/ {
    proxy_pass http://旧WindowsIP:8080/;
    proxy_set_header Host $host;
    ...
}
```

这样用户访问 `https://tools.marschat.online/kb/` → 就是知识库的后端 API。
