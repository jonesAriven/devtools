# Private-Knowledge-Base 路径规划与部署配置

> 所有路径统一以 `/kb/` 为全局上下文前缀，Nginx 按前缀路由，不会和其他服务冲突。
>
> **架构更新（2026-06-26）**：后端已从单体重构为微服务（kb-gateway:8090 → kb-auth:8081/kb-file:8082/kb-knowledge:8083/kb-ops:8084）。
> 网关按 `/kb/api/{module}/**` 路由到对应微服务（StripPrefix=2）。路径规划本身不变。

## 1. 路径分层

```
/kb/
├── api/                    ← 后端API（Nginx代理到Spring Boot）
│   ├── auth/               ← 鉴权模块
│   ├── user/               ← 用户模块
│   ├── space/              ← 空间模块
│   ├── folder/             ← 目录模块
│   ├── file/               ← 文件模块
│   ├── doc/                ← 笔记模块
│   ├── web/                ← 网页收藏模块
│   ├── search/             ← 搜索模块
│   ├── tag/                ← 标签模块
│   ├── share/              ← 分享模块
│   ├── version/            ← 版本模块
│   ├── trash/              ← 回收站模块
│   ├── log/                ← 操作日志模块
│   ├── bucket/             ← 存储桶模块
│   ├── ai/                 ← AI模块（后续）
│   ├── notification/       ← 通知模块（后续）
│   └── actuator/           ← 健康检查
│
├── s/                      ← 前端静态资源（Nginx直接服务）
│   ├── assets/             ← JS/CSS/图片等构建产物（带hash，长期缓存）
│   └── index.html          ← SPA入口
│
├── share/                  ← 分享访问页（无需登录，特殊路由）
│   └── {code}              ← 分享码访问
│
└── *                       ← 其他所有路径 → SPA fallback到index.html
```

## 4. Nginx 配置

```nginx
server {
    listen 443 ssl;
    server_name tools.marschat.online;

    ssl_certificate     /etc/nginx/ssl/tools.marschat.online.pem;
    ssl_certificate_key /etc/nginx/ssl/tools.marschat.online.key;

    # ============================================
    # 1. 后端API代理：/kb/api/ → Spring Boot
    # ============================================
    location /kb/api/ {
        # VM_Tailscale_IP 需替换为旧Windows安装Tailscale后的IP
        proxy_pass http://VM_Tailscale_IP:8080/kb/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 5s;
        proxy_read_timeout 60s;
        client_max_body_size 200m;
    }

    # ============================================
    # 2. 静态资源：/kb/s/ → Vue3构建产物
    # ============================================
    location /kb/s/assets/ {
        alias /data/knowledge-base/web/assets/;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    location /kb/s/ {
        alias /data/knowledge-base/web/;
        expires 7d;
    }

    # ============================================
    # 3. 分享页面：/kb/share/ → SPA处理（无需登录）
    # ============================================
    location /kb/share/ {
        try_files $uri /kb/s/index.html;
    }

    # ============================================
    # 4. SPA fallback：其他/kb/路径 → index.html
    # ============================================
    location /kb/ {
        try_files $uri /kb/s/index.html;
    }

    # ============================================
    # 5. 根路径重定向
    # ============================================
    location = / {
        return 302 /kb/;
    }

    location = /kb {
        return 302 /kb/;
    }
}

# HTTP → HTTPS 重定向
server {
    listen 80;
    server_name tools.marschat.online;
    return 301 https://$host$request_uri;
}
```

## 8. 分层部署网络拓扑

```
用户 → tools.marschat.online(443)
         → Nginx（SSL终结 + 静态资源）
            → /kb/api/* → Tailscale隧道 → Spring Boot(8080)
                                             → MySQL(3306) / MongoDB(27017) / MinIO(9000) / MeiliSearch(7700)
            → /kb/s/*   → 静态文件(/data/knowledge-base/web/)
            → /kb/*     → SPA fallback(index.html)
```

### 腾讯云2号（1.117.70.30）— 接入层
- Nginx：SSL终结 + 反向代理 + 静态资源服务
- Redis：缓存 + 会话（可选，也可放VM内）

### VirtualBox VM（旧Windows宿主机 192.168.31.243）— 全栈层
- Spring Boot：业务逻辑
- MySQL 8.0：关系元数据
- MongoDB 7.0：内容持久化
- MinIO：文件二进制（数据目录挂载E盘机械盘）
- MeiliSearch：全文搜索
- Redis：缓存 + 会话

### Tailscale 网络
- 腾讯云 Tailscale IP: 100.110.114.16
- 旧Windows Tailscale IP: 待分配（装Tailscale后获取）
- VM通过桥接模式使用宿主机网络
