| 属性 | 值 |
|------|-----|
| 版本 | v1.5.0 |

## 1. 数据库总览

每个微服务独立数据库，禁止跨库JOIN。所有表统一使用 `COLLATE=utf8mb4_unicode_ci`。

| 数据库 | 微服务 | 初始化脚本 |
|--------|--------|-----------|
| kb_auth | kb-auth | init-sql/02-kb-auth.sql |
| kb_file | kb-file | init-sql/03-kb-file.sql |
| kb_knowledge | kb-knowledge | init-sql/05-kb-knowledge.sql |
| kb_ops | kb-ops | init-sql/04-kb-ops.sql |
| kb_intelligence | kb-intelligence | init-sql/06-kb-intelligence.sql |

数据库由 `init-sql/01-create-databases.sql` 统一创建。

## 4. kb_knowledge 数据库

### space（知识空间表）

知识库顶层组织单位，每个空间有独立的文件夹树。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `user_id` | `BIGINT NOT NULL` | 所属用户 |
| `name` | `VARCHAR(100) NOT NULL` | 空间名 |
| `type` | `VARCHAR(20) DEFAULT 'private'` | 类型（private/team/public） |
| `description` | `VARCHAR(500)` | 描述 |
| `status` | `TINYINT DEFAULT 1` | 状态 |
| `deleted` | `TINYINT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_user_id (user_id)`

### folder（文件夹表）

知识空间内的目录树，支持多级嵌套（parent_id=0 为根）。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `space_id` | `BIGINT NOT NULL` | 所属空间ID |
| `parent_id` | `BIGINT DEFAULT 0` | 父文件夹ID（0=根目录） |
| `name` | `VARCHAR(200) NOT NULL` | 文件夹名 |
| `sort_order` | `INT DEFAULT 0` | 排序 |
| `deleted` | `TINYINT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_space_id (space_id)`、`idx_parent_id (parent_id)`

### doc（文档表）

知识库核心文档表，文档内容存储在 MongoDB（按版本快照）。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `folder_id` | `BIGINT NOT NULL` | 所属文件夹ID |
| `user_id` | `BIGINT NOT NULL` | 创建用户 |
| `title` | `VARCHAR(500) NOT NULL` | 标题 |
| `starred` | `TINYINT DEFAULT 0` | 是否收藏（0/1） |
| `deleted` | `TINYINT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_folder_id (folder_id)`、`idx_user_id (user_id)`

> **注**：文档正文内容不在 MySQL 存储，按版本快照存入 MongoDB（`kb_knowledge_doc` 集合）。`space_id` 通过 `folder_id` 间接关联（folder 表含 space_id）。

### tag（标签表）

跨资源类型（文档/文件/网页/文件夹）的分类标签，支持颜色标识。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `user_id` | `BIGINT NOT NULL` | 所属用户 |
| `name` | `VARCHAR(100) NOT NULL` | 标签名 |
| `color` | `VARCHAR(20)` | 颜色（如 `#FF5733`） |
| `deleted` | `TINYINT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_user_name (user_id, name)`

### resource_tag（资源标签关联表）

实现标签与资源（文档/文件/网页/文件夹）的多对多关系。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `tag_id` | `BIGINT NOT NULL` | 标签ID（tag.id） |
| `resource_type` | `VARCHAR(20) NOT NULL` | 资源类型（file/doc/web/folder） |
| `resource_id` | `BIGINT NOT NULL` | 资源ID |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |

**索引**：`idx_tag_id (tag_id)`、`idx_resource (resource_type, resource_id)`

### share（分享表）

生成公开链接分享文档/文件/网页/文件夹，支持提取码、有效期、访问次数限制。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `user_id` | `BIGINT NOT NULL` | 创建分享的用户 |
| `resource_type` | `VARCHAR(20) NOT NULL` | 资源类型（file/doc/web/folder） |
| `resource_id` | `BIGINT NOT NULL` | 资源ID |
| `code` | `VARCHAR(50) NOT NULL` | 分享码（UUID，URL 路径参数） |
| `extract_code` | `VARCHAR(10)` | 提取码（4 位数字，可空=无提取码） |
| `expire_at` | `DATETIME` | 过期时间（NULL=永久有效） |
| `view_count` | `INT DEFAULT 0` | 累计访问次数 |
| `deleted` | `TINYINT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`uk_code (code)` 唯一、`idx_user_id (user_id)`

### share_access_log（分享访问日志表）

记录每次分享链接的访问信息，用于审计与统计。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `share_id` | `BIGINT NOT NULL` | 分享ID（share.id） |
| `ip` | `VARCHAR(50)` | 访问者 IP |
| `user_agent` | `VARCHAR(500)` | 浏览器 UA |
| `accessed_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 访问时间 |

**索引**：`idx_share_id (share_id)`

### version（版本表）

记录文档/文件/网页的版本快照，支持历史回滚。版本内容存储在 MongoDB。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `resource_type` | `VARCHAR(20) NOT NULL` | 资源类型（file/doc/web） |
| `resource_id` | `BIGINT NOT NULL` | 资源ID |
| `version_num` | `INT DEFAULT 1` | 版本号（递增） |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |

**索引**：`idx_resource (resource_type, resource_id)`

### web_page（网页收藏表）

保存网页内容快照，支持离线阅读与重新抓取。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `folder_id` | `BIGINT NOT NULL` | 所属文件夹ID |
| `user_id` | `BIGINT NOT NULL` | 收藏用户 |
| `url` | `VARCHAR(2000) NOT NULL` | 原始网页 URL |
| `title` | `VARCHAR(500) NOT NULL` | 网页标题 |
| `snapshot_path` | `VARCHAR(1000)` | 正文快照存储路径（MinIO） |
| `starred` | `TINYINT DEFAULT 0` | 是否收藏（0/1） |
| `deleted` | `TINYINT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_folder_id (folder_id)`、`idx_user_id (user_id)`

## 5. kb_ops 数据库

### host（主机表）
| 列 | 类型 | 说明 |
|----|------|------|
| id | BIGINT AUTO_INCREMENT | 主键 |
| name | VARCHAR(100) | 主机名 |
| ip | VARCHAR(45) | IP地址 |
| tailscale_ip | VARCHAR(45) | Tailscale IP |
| ssh_port | INT | SSH端口 |
| username | VARCHAR(50) | SSH用户名 |
| password_encrypted | VARCHAR(500) | AES加密密码 |
| role | VARCHAR(50) | 角色 |
| status | VARCHAR(20) | 运行状态 |

### ops_port（端口表）

记录主机上对外开放或内部监听的端口信息，关联主机与服务。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `host_id` | `BIGINT` | 关联主机ID（ops_host.id） |
| `port` | `INT` | 端口号 |
| `protocol` | `VARCHAR(16)` | 协议（TCP/UDP/HTTP/HTTPS） |
| `service_id` | `BIGINT` | 关联服务ID（ops_service.id，可空） |
| `purpose` | `VARCHAR(255)` | 用途说明（如"Nginx 入口"、"MySQL 数据库"） |
| `status` | `TINYINT` | 状态（1=监听中、0=未监听、2=异常） |
| `exposed` | `TINYINT` | 是否对外暴露（1=公网可达、0=仅内网） |
| `remark` | `VARCHAR(500)` | 备注 |
| `created_at` | `DATETIME` | 创建时间 |
| `updated_at` | `DATETIME` | 更新时间 |

**索引**：`idx_host (host_id)`、`idx_service (service_id)`、`uk_host_port (host_id, port)` 唯一

### ops_credential（凭据表）

集中管理各类账号密码/密钥，密码字段使用 AES-256-GCM 加密存储，列表接口默认不返回明文。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `name` | `VARCHAR(100)` | 凭据名称（如"web-server SSH root"） |
| `type` | `VARCHAR(32)` | 类型（SSH/DB/API_KEY/TOKEN/OTHER） |
| `username` | `VARCHAR(100)` | 用户名 |
| `password_encrypted` | `TEXT` | AES-256-GCM 加密后的密码（密文） |
| `secret_key` | `VARCHAR(255)` | 其他密钥（如 API Token、Access Key） |
| `host_id` | `BIGINT` | 关联主机ID（可空） |
| `service_id` | `BIGINT` | 关联服务ID（可空） |
| `remark` | `VARCHAR(500)` | 备注 |
| `created_at` | `DATETIME` | 创建时间 |
| `updated_at` | `DATETIME` | 更新时间 |

**索引**：`idx_type (type)`、`idx_host (host_id)`、`idx_service (service_id)`

### ops_domain（域名表）

管理自有域名及 SSL 证书到期信息，辅助运维巡检与告警。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `domain` | `VARCHAR(255)` | 域名（如 kb.marschat.online） |
| `type` | `VARCHAR(32)` | 类型（TOP_LEVEL/SUB_DOMAIN/WILDCARD） |
| `purpose` | `VARCHAR(255)` | 用途说明（如"知识库公网入口"） |
| `registrar` | `VARCHAR(100)` | 注册商（如阿里云、腾讯云） |
| `expires_at` | `DATETIME` | 域名到期时间 |
| `ssl_expires_at` | `DATETIME` | SSL 证书到期时间 |
| `status` | `TINYINT` | 状态（1=正常、0=已过期、2=即将过期） |
| `remark` | `VARCHAR(500)` | 备注 |
| `created_at` | `DATETIME` | 创建时间 |
| `updated_at` | `DATETIME` | 更新时间 |

**索引**：`idx_status (status)`、`uk_domain (domain)` 唯一

### ops_dependency（依赖关系表）

记录服务间依赖关系，用于拓扑展示与影响面分析。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `service_id` | `BIGINT` | 当前服务ID（ops_service.id） |
| `service_name` | `VARCHAR(100)` | 当前服务名称（冗余，便于展示） |
| `depends_on_service_id` | `BIGINT` | 依赖的服务ID |
| `depends_on_service_name` | `VARCHAR(100)` | 依赖的服务名称（冗余） |
| `dependency_type` | `VARCHAR(32)` | 依赖类型（RUNTIME/STARTUP/OPTIONAL/DATA） |
| `remark` | `VARCHAR(500)` | 备注 |
| `created_at` | `DATETIME` | 创建时间 |
| `updated_at` | `DATETIME` | 更新时间 |

**索引**：`idx_service (service_id)`、`idx_depends_on (depends_on_service_id)`

### ops_service（服务表）

记录部署在各主机上的服务实例，关联主机与端口。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `name` | `VARCHAR(128) NOT NULL` | 服务名称 |
| `type` | `VARCHAR(64)` | 服务类型（web/db/cache/mq 等） |
| `version` | `VARCHAR(64)` | 当前版本 |
| `port` | `INT` | 服务端口 |
| `host_id` | `BIGINT` | 部署主机ID（ops_host.id） |
| `deploy_path` | `VARCHAR(512)` | 部署路径 |
| `status` | `INT DEFAULT 1` | 状态（1=运行中 0=已停止 2=异常） |
| `dependencies` | `VARCHAR(512)` | 依赖服务（逗号分隔 service name） |
| `tags` | `VARCHAR(512)` | 标签 |
| `remark` | `VARCHAR(512)` | 备注 |
| `deleted` | `INT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_host_id (host_id)`、`idx_name (name)`、`idx_status (status)`

### ops_change_log（部署/变更记录表）

记录每次部署或回滚操作的版本、操作人、结果，用于变更追溯。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `service_id` | `BIGINT NOT NULL` | 服务ID（ops_service.id） |
| `service_name` | `VARCHAR(128)` | 服务名称（冗余便于查询） |
| `host_id` | `BIGINT` | 部署主机ID |
| `version` | `VARCHAR(64)` | 部署版本 |
| `previous_version` | `VARCHAR(64)` | 回滚前的版本 |
| `operator` | `VARCHAR(64)` | 操作人 |
| `deploy_time` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 部署时间 |
| `result` | `INT DEFAULT 1` | 结果（1=成功 0=失败） |
| `rollback` | `INT DEFAULT 0` | 是否回滚（0=普通部署 1=回滚） |
| `rollback_info` | `VARCHAR(512)` | 回滚信息/说明 |
| `remark` | `VARCHAR(512)` | 备注 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |

**索引**：`idx_service_id (service_id)`、`idx_deploy_time (deploy_time)`

> **注**：文档早期版本称此表为 `deployment_record`，实际表名为 `ops_change_log`。

### ops_knowledge（运维知识表）

存储运维相关的文档、排障记录、巡检规范等知识内容。

| 字段 | 类型 | 说明 |

| `title` | `VARCHAR(256) NOT NULL` | 标题 |
| `category` | `VARCHAR(64)` | 分类（部署/排障/巡检/规范等） |
| `content` | `MEDIUMTEXT` | 内容（Markdown） |
| `tags` | `VARCHAR(512)` | 标签（逗号分隔） |
| `host_id` | `BIGINT` | 关联主机ID |
| `service_id` | `BIGINT` | 关联服务ID |
| `author` | `VARCHAR(64)` | 作者 |
| `view_count` | `INT DEFAULT 0` | 查看次数 |
| `deleted` | `INT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_category (category)`、`idx_host_id (host_id)`、`idx_service_id (service_id)`

### operation_log（操作日志表）

自动记录系统所有关键操作（登录、CRUD、部署等），用于审计与追溯。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `user_id` | `BIGINT` | 操作用户ID |
| `username` | `VARCHAR(100)` | 用户名 |
| `action` | `VARCHAR(50) NOT NULL` | 操作类型（LOGIN/UPLOAD/DELETE/UPDATE 等） |
| `resource_type` | `VARCHAR(50)` | 资源类型 |
| `resource_id` | `BIGINT` | 资源ID |
| `detail` | `VARCHAR(2000)` | 操作详情 |
| `ip` | `VARCHAR(50)` | 操作 IP |
| `user_agent` | `VARCHAR(500)` | 浏览器 UA |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |

**索引**：`idx_user_id (user_id)`、`idx_action (action)`、`idx_created_at (created_at)`

### ops_conflict（矛盾检测结果表）

存储矛盾检测引擎发现的问题，包括端口占用、版本不一致、依赖循环等。

| 字段 | 类型 | 说明 |

## 8. MeiliSearch 搜索引擎

MyKNG 使用 **MeiliSearch** 作为全文搜索引擎，分为两套独立索引体系：

### 8.1 用户侧全文搜索索引（kb-knowledge，已实现）

服务于普通用户的个人知识库搜索，共 3 个索引：

#### 8.1.1 kb_docs（笔记索引）

| 字段 | 类型 | 属性 | 说明 |
|------|------|------|------|

| docId | Number | filterable | 文档 ID |

| starred | Boolean | filterable | 是否收藏 |
| createdAt | String | displayed | 创建时间 |
| updatedAt | String | displayed | 更新时间 |

#### 8.1.2 kb_webpages（网页收藏索引）

| 字段 | 类型 | 属性 | 说明 |

|------|------|------|------|

| fileId | Number | filterable | 文件 ID |
| userId | Number | filterable | 所属用户 ID |
| name | String | searchable, displayed | 文件名 |

| content | String | searchable | 文件解析后的纯文本内容 |
| starred | Boolean | filterable | 是否收藏 |
| createdAt | String | displayed | 创建时间 |

#### 8.1.4 索引同步机制

- **写入时机**：资源创建/更新时异步调用 `SearchIndexService.indexDoc()` / `indexWebPage()` / `indexFile()` 写入索引
- **删除时机**：资源删除时异步调用 `removeDocIndex()` / `removeWebPageIndex()` / `removeIndex()` 删除索引
- **启动初始化**：`SearchIndexService.initIndexes()` 在服务启动时创建索引并设置 filterableAttributes
- **主键策略**：所有索引主键显式指定为 `id`，避免 MeiliSearch 自动推断失败
- **降级策略**：MeiliSearch 不可用时，搜索接口自动回退到 MySQL LIKE 查询（doc + web，file 暂不支持降级）

#### kn_vectors（知识向量索引 — Layer 4）

支持关键词搜索、语义搜索（向量相似度）、混合搜索三种模式。

## 9. 数据库变更规范

- **禁止删除表或清空数据**，所有变更以 `ALTER TABLE` 方式升级
- 新增列：先查 `information_schema.COLUMNS` 判断是否存在
- 新增索引：先查 `information_schema.STATISTICS` 判断是否存在
- 所有DDL变更需提供回滚脚本
- 变更脚本归档到 `sql/` 目录，按 Flyway 版本号命名
