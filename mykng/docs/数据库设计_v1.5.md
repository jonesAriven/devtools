## 1. 数据库总览

每个微服务独立数据库，禁止跨库JOIN。所有表统一使用 `COLLATE=utf8mb4_unicode_ci`。

| 数据库 | 微服务 | 初始化脚本 |
|--------|--------|-----------|
| kb_auth | kb-auth | init-sql/02-kb-auth.sql |
| kb_file | kb-file | init-sql/03-kb-file.sql |
| kb_knowledge | kb-knowledge | init-sql/05-kb-knowledge.sql |
| kb_intelligence | kb-intelligence | init-sql/06-kb-intelligence.sql |

数据库由 `init-sql/01-create-databases.sql` 统一创建。

## 4. kb_knowledge 数据库

### space（知识空间表）

知识库顶层组织单位，每个空间有独立的文件夹树。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `user_id` | `BIGINT NOT NULL` | 所属用户 |
| `name` | `VARCHAR(100) NOT NULL` | 空间名 |
| `type` | `VARCHAR(20) DEFAULT 'private'` | 类型（private/team/public） |
| `description` | `VARCHAR(500)` | 描述 |
| `status` | `TINYINT DEFAULT 1` | 状态 |
| `deleted` | `TINYINT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_user_id (user_id)`

### folder（文件夹表）

知识空间内的目录树，支持多级嵌套（parent_id=0 为根）。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `space_id` | `BIGINT NOT NULL` | 所属空间ID |
| `parent_id` | `BIGINT DEFAULT 0` | 父文件夹ID（0=根目录） |
| `name` | `VARCHAR(200) NOT NULL` | 文件夹名 |
| `sort_order` | `INT DEFAULT 0` | 排序 |
| `deleted` | `TINYINT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_space_id (space_id)`、`idx_parent_id (parent_id)`

### doc（文档表）

知识库核心文档表，文档内容存储在 MongoDB（按版本快照）。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `folder_id` | `BIGINT NOT NULL` | 所属文件夹ID |
| `user_id` | `BIGINT NOT NULL` | 创建用户 |
| `title` | `VARCHAR(500) NOT NULL` | 标题 |
| `starred` | `TINYINT DEFAULT 0` | 是否收藏（0/1） |
| `deleted` | `TINYINT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_folder_id (folder_id)`、`idx_user_id (user_id)`

> **注**：文档正文内容不在 MySQL 存储，按版本快照存入 MongoDB（`kb_knowledge_doc` 集合）。`space_id` 通过 `folder_id` 间接关联（folder 表含 space_id）。

### tag（标签表）

跨资源类型（文档/文件/网页/文件夹）的分类标签，支持颜色标识。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `user_id` | `BIGINT NOT NULL` | 所属用户 |
| `name` | `VARCHAR(100) NOT NULL` | 标签名 |
| `color` | `VARCHAR(20)` | 颜色（如 `#FF5733`） |
| `deleted` | `TINYINT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_user_name (user_id, name)`

### resource_tag（资源标签关联表）

实现标签与资源（文档/文件/网页/文件夹）的多对多关系。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `tag_id` | `BIGINT NOT NULL` | 标签ID（tag.id） |
| `resource_type` | `VARCHAR(20) NOT NULL` | 资源类型（file/doc/web/folder） |
| `resource_id` | `BIGINT NOT NULL` | 资源ID |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |

**索引**：`idx_tag_id (tag_id)`、`idx_resource (resource_type, resource_id)`

### share（分享表）

生成公开链接分享文档/文件/网页/文件夹，支持提取码、有效期、访问次数限制。

| 字段 | 类型 | 说明 |
|------|------|------|

| `resource_type` | `VARCHAR(20) NOT NULL` | 资源类型（file/doc/web/folder） |

| `code` | `VARCHAR(50) NOT NULL` | 分享码（UUID，URL 路径参数） |
| `extract_code` | `VARCHAR(10)` | 提取码（4 位数字，可空=无提取码） |
| `expire_at` | `DATETIME` | 过期时间（NULL=永久有效） |
| `view_count` | `INT DEFAULT 0` | 累计访问次数 |
| `deleted` | `TINYINT DEFAULT 0` | 逻辑删除 |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`uk_code (code)` 唯一、`idx_user_id (user_id)`

### share_access_log（分享访问日志表）

记录每次分享链接的访问信息，用于审计与统计。

### version（版本表）

记录文档/文件/网页的版本快照，支持历史回滚。版本内容存储在 MongoDB。

| 字段 | 类型 | 说明 |

## 5. kb_intelligence 数据库

> 知识引擎四层数据模型：L1 索引层（MySQL kn_doc）、L2 参数层（kn_command/kn_timeline/kn_doc_entity_ref）、L3 内容层（MongoDB kn_content）、L4 向量层（MeiliSearch kn_vectors）。
>
> **注**：原 L2 参数层复用 kb_ops 库的 ops_* 表，kb-ops 模块剥离后该关联已失效，kn_doc_entity_ref 暂无对应实体表。

### kn_doc（知识文档元数据表 — Layer 1）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `BIGINT AUTO_INCREMENT` | 主键 |
| `source_id` | `VARCHAR(64) NOT NULL` | 导入批次ID |
| `title` | `VARCHAR(256) NOT NULL` | 文档标题（从文件名或H1提取） |
| `file_path` | `VARCHAR(768) NOT NULL` | 原始文件绝对路径 |
| `file_name` | `VARCHAR(256) NOT NULL` | 文件名 |
| `file_type` | `VARCHAR(16) DEFAULT 'md'` | 文件类型（md/txt/png） |
| `doc_type` | `VARCHAR(16) NOT NULL` | 文档类型（TABLE/PLAN/TIMELINE/GRAPH/RULE） |
| `category` | `VARCHAR(64)` | 一级目录分类（备忘录/知识/经验） |
| `tags` | `VARCHAR(512)` | 标签（逗号分隔） |
| `summary` | `VARCHAR(512)` | AI摘要（100字） |
| `content_hash` | `VARCHAR(64)` | 内容SHA256（增量更新） |
| `word_count` | `INT DEFAULT 0` | 字数 |
| `section_count` | `INT DEFAULT 0` | 章节数 |
| `status` | `VARCHAR(16) DEFAULT 'ACTIVE'` | 状态（ACTIVE/ARCHIVED） |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` | 创建时间 |
| `updated_at` | `DATETIME ON UPDATE CURRENT_TIMESTAMP` | 更新时间 |

**索引**：`idx_source (source_id)`、`idx_type (doc_type)`、`idx_category (category)`、`idx_hash (content_hash)`、`uk_path (file_path(255))` 唯一

## 7. MeiliSearch 搜索引擎

MyKNG 使用 **MeiliSearch** 作为全文搜索引擎，分为两套独立索引体系：

### 7.1 用户侧全文搜索索引（kb-knowledge，已实现）

服务于普通用户的个人知识库搜索，共 3 个索引：

#### 7.1.1 kb_docs（笔记索引）

| 字段 | 类型 | 属性 | 说明 |
|------|------|------|------|
| id | String | primary key | 主键 = docId 字符串 |
| docId | Number | filterable | 文档 ID |
| userId | Number | filterable | 所属用户 ID |
| folderId | Number | filterable | 文件夹 ID |
| title | String | searchable, displayed | 文档标题 |
| content | String | searchable | 文档正文（纯文本） |
| starred | Boolean | filterable | 是否收藏 |
| createdAt | String | displayed | 创建时间 |
| updatedAt | String | displayed | 更新时间 |

#### 7.1.2 kb_webpages（网页收藏索引）

| 字段 | 类型 | 属性 | 说明 |
|------|------|------|------|
| id | String | primary key | 主键 = webId 字符串 |
| webId | Number | filterable | 网页 ID |
| userId | Number | filterable | 所属用户 ID |
| folderId | Number | filterable | 文件夹 ID |
| url | String | displayed | 网页 URL |
| title | String | searchable, displayed | 网页标题 |
| content | String | searchable | 网页正文（纯文本） |
| starred | Boolean | filterable | 是否收藏 |
| createdAt | String | displayed | 创建时间 |

#### 7.1.3 kb_files（文件索引）

| 字段 | 类型 | 属性 | 说明 |
|------|------|------|------|
| id | String | primary key | 主键 = fileId 字符串 |
| fileId | Number | filterable | 文件 ID |
| userId | Number | filterable | 所属用户 ID |
| name | String | searchable, displayed | 文件名 |
| type | String | filterable | 文件类型 |
| content | String | searchable | 文件解析后的纯文本内容 |
| starred | Boolean | filterable | 是否收藏 |
| createdAt | String | displayed | 创建时间 |

#### 7.1.4 索引同步机制

- **写入时机**：资源创建/更新时异步调用 `SearchIndexService.indexDoc()` / `indexWebPage()` / `indexFile()` 写入索引
- **删除时机**：资源删除时异步调用 `removeDocIndex()` / `removeWebPageIndex()` / `removeIndex()` 删除索引
- **启动初始化**：`SearchIndexService.initIndexes()` 在服务启动时创建索引并设置 filterableAttributes
- **主键策略**：所有索引主键显式指定为 `id`，避免 MeiliSearch 自动推断失败
- **降级策略**：MeiliSearch 不可用时，搜索接口自动回退到 MySQL LIKE 查询（doc + web，file 暂不支持降级）

#### kn_vectors（知识向量索引 — Layer 4）

支持关键词搜索、语义搜索（向量相似度）、混合搜索三种模式。

## 8. 数据库变更规范

- **禁止删除表或清空数据**，所有变更以 `ALTER TABLE` 方式升级
- 新增列：先查 `information_schema.COLUMNS` 判断是否存在
- 新增索引：先查 `information_schema.STATISTICS` 判断是否存在
- 所有DDL变更需提供回滚脚本
- 变更脚本归档到 `sql/` 目录，按 Flyway 版本号命名
