## 二、需求清单（按优先级）

### P0 — 用户明确要求

#### R1. 新建笔记支持多格式

* **需求**：新建笔记时支持选择格式：Markdown / 富文本(HTML)

* **场景**：技术用户偏好 Markdown（可纯文本编辑+预览），普通用户偏好富文本

* **验收**：

  * 新建页提供"格式"选择（默认富文本，可切 Markdown）

  * Markdown 笔记使用 md 编辑器（左编辑右预览 或 所见即所得）

  * 富文本笔记保持现有 wangEditor 体验

  * Doc 实体新增 `format` 字段（`html` / `markdown`），后端按 format 存储与返回

#### R2. 上传文档支持在线编辑

* **需求**：上传的 txt/md/json/csv 等文本类文件可直接在线编辑并保存

* **场景**：上传一个 .md 文件后，希望直接在知识库内编辑内容，不必下载→修改→重新上传

* **验收**：

  * 文本类文件（txt/md/json/csv/xml/html/log 等）详情页新增"编辑"按钮

  * 编辑后保存：更新 MinIO 原文件 + 更新 MongoDB 解析内容 + 重建 MeiliSearch 索引

  * 二进制文件（docx/xlsx/pdf）暂不支持编辑（保持预览）— 这是商用产品也受限的能力

* **设计取舍**：docx/xlsx 在线编辑需要 OnlyOffice/Collabora 等重型组件，本期不做

#### R3. 知识库树形展示（含资源）

* **需求**：左侧侧栏树形展示"文件夹+笔记+文件+网页"统一层级

* **场景**：当前 FolderTree 仅展示文件夹，需切换到 ResourceList 才看内容；希望树中直接看到所有资源

* **验收**：

  * 树节点类型：📁 文件夹 / 📄 笔记 / 📎 文件 / 🌐 网页

  * 节点图标区分类型

  * 点击笔记节点 → 直接打开编辑器

  * 点击文件节点 → 打开文件详情

  * 支持拖拽资源到文件夹（移动）

  * 保留现有 FolderTree 作为"仅文件夹"模式可切换

### P1 — 取长补短增强

#### R4. 文档大纲（TOC）

* 从 Markdown/HTML 内容提取标题（h1-h3），右侧悬浮显示大纲

* 点击大纲跳转到对应标题

#### R5. Markdown 编辑器

* 使用 Milkdown 或 mdEditor-v3（轻量、Vue3 友好）

* 支持：标题、列表、代码块、表格、引用、链接、图片

* 所见即所得（非分屏）

#### R6. 文档模板

* 新建笔记可选模板：空白 / 会议纪要 / 周报 / 技术文档 / 待办清单

* 模板预置内容，一键创建

#### R7. 快捷键

* `Ctrl+S` 保存

* `Ctrl+Enter` 新建一行

* `Ctrl+B/I/U` 加粗/斜体/下划线（富文本已有，需确认 Markdown 编辑器也有）

### P2 — 后续迭代

* R8. 双向链接（\[\[doc title]]）— Obsidian 风格

* R9. 文档版本对比（diff 视图）

* R10. 文档导出（PDF/Markdown 导出）

## 三、技术方案

### 3.1 后端改造

#### 3.1.1 Doc 实体新增 format 字段

```sql
-- 先查询列是否存在，不存在才添加
SELECT COUNT(*) FROM information_schema.COLUMNS
  WHERE TABLE_SCHEMA='kb' AND TABLE_NAME='doc' AND COLUMN_NAME='format';
-- 不存在时执行：
ALTER TABLE kb.doc ADD COLUMN format VARCHAR(20) NOT NULL DEFAULT 'html'
  COMMENT '文档格式: html/markdown';
```

#### 3.1.2 DocController/Service 调整

* `POST /doc`：请求体新增 `format` 字段（默认 `html`）

* `GET /doc/{id}`：响应包含 `format` 字段

* `PUT /doc/{id}`：允许更新 format（可选，一期不强制）

* 校验：format ∈ {`html`, `markdown`}

#### 3.1.3 文件在线编辑 API（kb-file 模块）

新增端点：

* `PUT /file/{id}/content`：更新文本类文件内容

  * 请求体：`{ "content": "新内容" }`

  * 校验：文件必须是文本类（通过扩展名判断）

  * 流程：

    1. 将新内容写为 InputStream 上传到 MinIO（覆盖原文件）
    2. 更新 MongoDB FileContent（新增版本，标记 isCurrent）
    3. 新增 Version 记录
    4. 异步更新 MeiliSearch 索引

  * 权限：仅文件所有者可编辑

#### 3.1.4 资源树 API

新增端点：

* `GET /folder/tree-with-resources/{spaceId}`：返回文件夹+资源统一树

  * 树节点结构：

    ```json
    {
      "id": 1, "name": "我的文件夹", "type": "folder",
      "children": [
        {"id": 1, "name": "笔记1", "type": "doc", "format": "markdown"},
        {"id": 5, "name": "report.xlsx", "type": "file"},
        {"id": 8, "name": "百度", "type": "web", "url": "..."}
      ]
    }
    ```

  * 实现：复用现有 Folder 树，对每个 folder 查询其下的 doc/file/webpage 填入 children

### 3.2 前端改造

#### 3.2.1 新建笔记支持格式选择（R1）

* `DocCreateView.vue` 新增 format 单选（富文本 / Markdown）

* format=html 时用 wangEditor（现有）

* format=markdown 时用 md-editor-v3（新增依赖）

#### 3.2.2 Markdown 编辑器（R5）

* 依赖：`md-editor-v3`（Vue3 原生、轻量、支持暗色）

* 替换 DocEditView/DocCreateView 中 wangEditor 的条件渲染

#### 3.2.3 文件在线编辑（R2）

* `FileDetailView.vue` 文本类文件新增"编辑"按钮

* 编辑态：`<MdEditor v-model="content" />` 或 `<el-input type="textarea">`

* 保存：调用 `PUT /file/{id}/content`

#### 3.2.4 资源树（R3）

* 新增 `ResourceTree.vue` 组件

* 使用 el-tree 自定义节点渲染（图标+名称+类型徽章）

* 切换按钮：仅文件夹 / 含资源

#### 3.2.5 文档大纲（R4）

* `DocEditView.vue` 右侧新增 TOC 组件

* Markdown：正则提取 `^#{1,3}\s`

* HTML：解析 DOM 提取 h1-h3

#### 3.2.6 文档模板（R6）

* 新建页提供模板下拉

* 模板内容预置到编辑器

### 3.3 数据库变更（遵循 SOP 0.4.2）

| 变更               | 类型                     | 回滚                 |
| ---------------- | ---------------------- | ------------------ |
| doc 表新增 format 列 | ALTER TABLE ADD COLUMN | DROP COLUMN format |

无数据删除，无表删除。

### 3.4 MeiliSearch 索引变更

* kb\_docs 索引新增 `format` 字段到 `displayedAttributes` 和 `filterableAttributes`

* 通过 PATCH API 应用，无需重建索引

### 3.5 测试方案

* **单元测试**：DocServiceImpl（format 字段处理）、FileEditService

* **集成测试**：文件编辑 API、资源树 API

* **E2E**：新建 Markdown 笔记、编辑文本文件、资源树点击跳转

* **部署**：mykng 部署，浏览器验证
