## 一、系统概述

MyKNG 是一套私有化部署的个人知识库平台，支持文件管理、文档编辑、网页收藏、全文搜索、内容分享、运维看板等功能。系统采用微服务架构，所有数据存储在私有服务器，确保数据安全。

### 核心功能

| 模块 | 说明 |
|------|------|
| 📁 知识空间 | 按空间组织内容（工作、学习、个人等），每个空间独立文件夹树 |
| 📝 文档管理 | 在线富文本编辑，支持版本控制、标签分类 |
| 📎 文件管理 | 上传各类文件（PDF/Word/图片等），自动解析内容供搜索 |
| 🌐 网页收藏 | 保存网页内容（自动抓取正文），支持离线阅读 |
| 🔍 全文搜索 | 基于 MeiliSearch，支持中英文混合搜索，毫秒级响应 |
| 📤 内容分享 | 生成分享链接，支持密码保护、有效期、访问日志 |
| 🗑️ 回收站 | 删除内容 30 天内可恢复，防止误删 |
| ⚙️ 运维看板 | 主机/服务/端口管理，自动矛盾检测，部署记录追踪 |
| 🔑 API Token | 第三方系统调用接口的长期令牌（默认 365 天） |

## 三、登录与认证

### 3.1 用户登录

1. 访问 https://kb.marschat.online/kb/
2. 自动跳转到登录页 `/login`
3. 输入用户名密码，点击"登录"
4. 登录成功后跳转到仪表盘 `/dashboard`

### 3.2 Token 类型

| Token | 有效期 | 用途 |
|-------|--------|------|
| Access Token | 15 分钟 | 浏览器请求业务接口（自动管理，无需手动操作） |
| Refresh Token | 7 天 | Access Token 过期后自动刷新（前端自动处理） |
| API Token | 默认 365 天，可永不过期 | 第三方系统调用 API |

### 3.3 创建 API Token（第三方系统接入）

适用于脚本、自动化工具、其他系统调用知识库 API：

1. 登录后进入"设置"页 `/settings`
2. 找到"API Token 管理"
3. 点击"创建 Token"，填写名称、有效期
4. **立即复制返回的 Token 明文**（仅展示一次，关闭后不可查看）
5. 调用 API 时在请求头携带：`Authorization: Bearer <token>`

调用示例：

```bash
curl -X POST https://kb.marschat.online/kb/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

## 四、功能使用指南

### 4.1 知识空间管理

知识空间是顶层的组织单位，每个空间有独立的文件夹树和权限。

**操作路径**：仪表盘 → 选择/创建空间

- 一个空间对应一个主题（如"工作笔记"、"学习资料"）
- 空间内可创建多级文件夹
- 文件夹下可存放：文档、文件、网页收藏

### 4.2 文档管理

#### 创建文档

1. 进入空间 → 选择目标文件夹
2. 点击"新建文档"
3. 输入标题，使用富文本编辑器编写内容
4. 自动保存（每 5 秒检测变更）
5. 可添加标签（如"重要"、"草稿"）

#### 编辑与版本

- 每次保存自动创建版本快照
- 在文档详情页可查看历史版本
- 支持回滚到任意历史版本

### 4.3 文件管理

#### 上传文件

1. 进入空间 → 选择文件夹
2. 点击"上传文件"或拖拽文件到上传区
3. 支持分片上传（大文件自动分片，断点续传）
4. 上传完成后自动解析内容（PDF/Word/文本文件）

**支持的文件类型**：
- 文档：PDF、Word（doc/docx）、文本（txt/md）
- 图片：jpg、png、gif、webp
- 其他：可上传任意类型，但不会解析内容

**文件大小限制**：单个文件最大 200MB

#### 文件详情

点击文件查看详情，包括：
- 文件基本信息（名称、大小、上传时间）
- 解析后的文本内容（支持搜索）
- 历史版本
- 关联标签

### 4.4 网页收藏

将网页内容保存到知识库，支持离线阅读。

1. 点击"新建网页收藏"
2. 输入网页 URL
3. 系统自动抓取网页正文（去除广告、导航等）
4. 保存后可随时查看，即使原网页失效也能阅读

### 4.5 全文搜索

**入口**：顶部搜索框 或 `/search` 页

- 支持中英文混合搜索
- 搜索范围：文档内容、文件解析内容、网页收藏正文、标题、标签
- 支持高亮显示匹配关键词
- 搜索结果按相关度排序

### 4.6 内容分享

将文档/文件生成公开链接，分享给未登录用户访问。

1. 在资源详情页点击"分享"
2. 配置分享选项：
   - 提取码（可选，4 位数字）
   - 有效期（1 天 / 7 天 / 30 天 / 永久）
   - 访问次数限制（可选）
3. 生成分享链接：`https://kb.marschat.online/kb/share/{code}`
4. 复制链接发送给对方

**访问者操作**：
1. 打开分享链接
2. 如有提取码，输入提取码
3. 查看分享内容（无需登录）
4. 访问记录会写入分享日志（创建者可查看）

### 4.7 回收站

删除的内容不会立即物理删除，而是进入回收站。

**操作路径**：左侧菜单 → 回收站 `/trash`

- 30 天内可恢复
- 30 天后自动清理
- 可手动"彻底删除"立即释放空间

### 4.8 运维看板（管理员）

运维看板用于管理主机、服务、端口、账密、域名等运维信息。

| 子模块 | 路径 | 功能 |
|--------|------|------|
| 运维总览 | `/ops` | 看板首页，统计概览 |
| 主机管理 | `/ops/hosts` | 主机列表、配置 SSH/Tailscale 信息 |
| 服务管理 | `/ops/services` | 服务列表、端口、依赖关系 |
| 矛盾检测 | `/ops/conflicts` | 自动检测配置冲突（端口占用、域名冲突等） |
| 运维知识 | `/ops/knowledge` | 运维文档、操作记录 |

## 五、API 接口速查

### 5.1 接口规范

- **接口总数**：96 个
- **统一前缀**：`/kb/api/`
- **返回格式**：`Result<T>`（含 code/message/data/traceId）
- **认证方式**：JWT Bearer Token（除登录、刷新、分享验证外）
- **完整文档**：[接口规范清单_v1.md](接口规范清单_v1.md)

### 5.2 常用接口

#### 用户认证

```bash
# 登录
POST /kb/api/auth/login
Body: {"username":"admin","password":"admin123"}
Response: {"accessToken":"...","refreshToken":"...","expiresIn":900000}

# 刷新令牌
POST /kb/api/auth/refresh
Body: {"refreshToken":"..."}

# 登出
POST /kb/api/auth/logout
Header: Authorization: Bearer <accessToken>

# 获取当前用户信息
GET /kb/api/user/profile
Header: Authorization: Bearer <accessToken>
```

#### 文档管理

```bash
# 创建文档
POST /kb/api/doc
Body: {"title":"标题","content":"内容","folderId":1}

# 获取文档详情
GET /kb/api/doc/{id}

# 更新文档
PUT /kb/api/doc/{id}
Body: {"title":"新标题","content":"新内容"}

# 删除文档（进回收站）
DELETE /kb/api/doc/{id}
```

#### 文件上传

```bash
# 初始化上传（获取 uploadId）
POST /kb/api/file/init
Body: {"filename":"文件.pdf","size":1024,"folderId":1}

# 上传分片
POST /kb/api/file/upload?uploadId=xxx&partNumber=1
Body: <binary>

# 合并分片
POST /kb/api/file/merge?uploadId=xxx
```

#### 搜索

```bash
# 全文搜索
GET /kb/api/search?q=关键词&page=1&size=20
```

#### 分享

```bash
# 创建分享
POST /kb/api/share
Body: {"resourceType":"doc","resourceId":1,"expireDays":7,"password":"1234"}

# 验证分享（公开访问）
GET /kb/api/share/verify/{code}
```

### 5.3 错误码

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| 200 | 成功 | - |
| 400 | 参数错误 | 检查请求参数格式 |
| 401 | 未认证 / Token 失效 | 重新登录或刷新 Token |
| 403 | 无权限 | 确认账号有对应权限 |
| 404 | 资源不存在 | 检查 ID 是否正确 |
| 409 | 资源冲突 | 检查唯一约束（如 IP 已存在） |
| 500 | 服务异常 | 查看 traceId 联系管理员排查 |

## 七、常见问题

### 7.1 浏览器证书警告

**现象**：访问 https://kb.marschat.online/kb/ 时浏览器提示"您的连接不是私密连接"或"证书无效"。

**原因**：kb.marschat.online 域名未备案，临时复用 nexus.marschat.online 的 SSL 证书，CN 不匹配。

**处理**：
- Chrome：点击"高级" → "继续前往 kb.marschat.online（不安全）"
- Firefox：点击"高级" → "接受风险并继续"
- Edge：点击"详细信息" → "继续转到此网页（不推荐）"

> 这是预期行为，不影响数据安全。后续将申请独立证书。

### 7.2 页面加载 504

**现象**：前端能打开但 API 返回 504 Gateway Timeout。

**原因**：VM (192.168.31.105) 离线，Nginx 无法连接 kb-gateway:8090。

**处理**：
1. 联系管理员检查 VM 状态
2. 管理员通过 Tailscale 后台查看 VM 在线状态
3. VM 恢复后自动恢复服务

### 7.3 上传大文件失败

**现象**：上传超过 100MB 的文件失败。

**检查项**：
- Nginx 限制：`client_max_body_size 200m`（已配置）
- 网络稳定性：分片上传依赖稳定网络
- 浏览器限制：建议使用 Chrome/Firefox 最新版

**处理**：分片上传失败可重试，已上传的分片不会重复传输。

### 7.4 搜索找不到内容

**可能原因**：
1. 文件类型不支持解析（如视频、压缩包）
2. 内容刚上传，索引尚未建立（默认 60 秒内同步）
3. 文件已删除（在回收站中，不参与搜索）

**处理**：
- 等待 1 分钟后重试
- 检查文件是否在回收站

### 7.5 分享链接打不开

**检查项**：
- 分享是否已过期
- 是否需要提取码（4 位数字）
- 资源是否已被删除（资源删除后分享失效）

## 附录：快速上手 Checklist

### 新用户首次使用

- [ ] 访问 https://kb.marschat.online/kb/
- [ ] 浏览器证书警告点击"继续访问"
- [ ] 使用 admin/admin123 登录
- [ ] 进入"设置"修改默认密码
- [ ] 创建第一个知识空间
- [ ] 创建第一个文档
- [ ] 尝试搜索功能

### 管理员部署检查

- [ ] VM (192.168.31.105) 在线且 Tailscale 已连接
- [ ] 腾讯云2号 Nginx 配置 `nginx -t` 通过
- [ ] `curl -k https://kb.marschat.online/kb/` 返回 200
- [ ] `curl -k -X POST https://kb.marschat.online/kb/api/auth/login -d '{"username":"admin","password":"admin123"}'` 返回 JSON
- [ ] 前端页面可正常加载
- [ ] 登录、文档创建、文件上传、搜索功能验证通过
