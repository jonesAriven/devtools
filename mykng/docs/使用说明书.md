> **版本**：v3.0
> **更新日期**：2026-07-02
> **适用对象**：最终用户（知识库使用者）+ 管理员（系统运维）
> **访问地址**：https://kb.marschat.online/kb/
> **架构要点**：所有服务（6 个微服务 + 5 个基础设施）均部署在 mykng-debian (192.168.31.105)，腾讯云2号 (1.117.70.30) 仅作 Nginx SSL 终结 + 纯反向代理，不存储任何静态文件。
> **v3.0 变更**：笔记功能增强（多格式/大纲/双向链接/模板/导出/版本对比）、文本文件在线编辑、资源树、全局搜索框、快捷新建按钮、搜索建议、Header布局优化。

## 一、系统概述

MyKNG 是一套私有化部署的个人知识库平台，支持文件管理、文档编辑、网页收藏、全文搜索、内容分享、运维看板、智能助手等功能。系统采用微服务架构，所有数据存储在私有服务器，确保数据安全。

### 核心功能

| 模块 | 说明 |
|------|------|
| 📁 知识空间 | 按空间组织内容（工作、学习、个人等），每个空间独立资源树 |
| 📝 文档管理 | 多格式笔记（Markdown / 富文本），支持文档大纲、双向链接、版本对比、文档模板、导出、标签分类、收藏、移动 |
| 📎 文件管理 | 上传各类文件（PDF/Word/图片等），自动解析内容供搜索，支持分片上传、文本文件在线编辑、收藏、移动 |
| 🌐 网页收藏 | 保存网页内容（自动抓取正文），支持离线阅读、重新抓取、收藏 |
| 🔍 全文搜索 | 基于 MeiliSearch，支持中英文混合搜索，毫秒级响应，支持搜索建议、结果高亮 |
| 🏷️ 标签管理 | 跨资源类型（文档/文件/网页）的标签分类，支持颜色标记、绑定/解绑 |
| 📤 内容分享 | 生成分享链接，支持提取码、有效期、访问次数限制 |
| 🗑️ 回收站 | 删除内容 30 天内可恢复，支持按类型筛选、清空回收站 |
| ⚙️ 运维看板 | 主机/服务/端口/账密/域名/依赖/部署记录/操作日志/矛盾检测/批量导入 |
| 🤖 智能助手 | 基于知识引擎的 AI 问答、语义搜索、实体识别、知识导入 |
| 🔑 API Token | 第三方系统调用接口的长期令牌（默认 365 天，支持启用/禁用） |

| | 全文搜索 | `/search` | MeiliSearch 搜索 |

| | 内容分享 | `/share` | 分享链接管理 |
| | 回收站 | `/trash` | 已删除内容恢复 |
| | 文件管理 | `/file` | 文件上传/管理 |

**菜单行为**：
- 点击分组标题展开/折叠

## 三、登录与认证

### 3.1 用户登录

1. 访问 https://kb.marschat.online/kb/
2. 自动跳转到登录页 `/login`
3. 输入用户名密码，点击"登录"
4. 登录成功后跳转到仪表盘 `/dashboard`

### 3.2 Token 类型

| Token | 有效期 | 用途 |
|-------|--------|------|
| Access Token | 15 分钟 | 浏览器请求业务接口（自动管理，无需手动操作） |
| Refresh Token | 7 天 | Access Token 过期后自动刷新（前端自动处理） |
| API Token | 默认 365 天，可永不过期 | 第三方系统调用 API |

### 3.3 创建 API Token（第三方系统接入）

适用于脚本、自动化工具、其他系统调用知识库 API：

1. 登录后进入"设置"页 `/settings`
2. 找到"API Token 管理"
3. 点击"创建 Token"，填写名称、有效期
4. **立即复制返回的 Token 明文**（仅展示一次，关闭后不可查看）
5. 调用 API 时在请求头携带：`Authorization: Bearer <token>`

调用示例：

```bash
curl -X POST https://kb.marschat.online/kb/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

## 四、功能使用指南

### 4.1 知识空间管理

知识空间是顶层的组织单位，每个空间有独立的文件夹树和权限。

**操作路径**：仪表盘 → 选择/创建空间

#### 4.1.1 创建空间

1. 仪表盘点击"新建空间"
2. 填写空间名称（如"工作笔记"）和描述
3. 提交后空间立即可用

```bash
POST /kb/api/space
Body: {"name":"工作笔记","description":"日常工作记录"}
```

#### 4.1.2 查看/编辑/删除空间

- **空间列表**：`GET /kb/api/space/list` — 返回当前用户所有空间
- **空间详情**：`GET /kb/api/space/{id}` — 含文件夹树概览
- **编辑空间**：`PUT /kb/api/space/{id}` — 修改名称/描述
- **删除空间**：`DELETE /kb/api/space/{id}` — ⚠️ 会级联删除空间下所有文件夹、文档、文件、网页，且不可恢复（不进回收站）

#### 4.1.3 资源树与文件夹树管理

**资源树视图**：
- 进入知识空间后，左侧显示完整资源树
- 包含：文件夹、文档、文件、网页收藏
- 支持展开/收起文件夹
- 点击节点直接跳转到对应资源
- 按类型显示不同图标，便于识别

**文件夹树管理**：
每个空间有独立的文件夹树，支持多级嵌套：

| 操作 | API | 说明 |
|------|-----|------|
| 获取文件夹树 | `GET /kb/api/folder/tree?spaceId={id}` | 必填 spaceId |
| 创建文件夹 | `POST /kb/api/folder` | Body: `{spaceId, parentId, name, sortOrder}` |
| 重命名文件夹 | `PUT /kb/api/folder/{id}` | Body: `{name}` |
| 删除文件夹 | `DELETE /kb/api/folder/{id}` | 仅空文件夹可删（含子文件夹/文档/网页时拒绝） |
| 移动文件夹 | `PUT /kb/api/folder/{id}/move` | Body: `{newParentId}` |
| 文件夹排序 | `PUT /kb/api/folder/{id}/sort` | Body: `{sortOrder}` |

> **删除约束**：文件夹下存在子文件夹、文档、网页收藏时拒绝删除，需先清空内容。

### 4.2 文档管理

#### 4.2.1 创建文档

1. 进入空间 → 选择目标文件夹
2. 点击"新建文档"或使用 Header 右侧"新建"快捷按钮
3. 选择文档格式：**Markdown** 或 **富文本(HTML)**
4. 可选择文档模板（空白文档/会议纪要/技术方案/学习笔记/个人日记/项目周报）
5. 输入标题，使用对应编辑器编写内容
6. 自动保存（每 5 秒检测变更）
7. 可添加标签（如"重要"、"草稿"）

```bash
POST /kb/api/doc
Body: {"title":"标题","content":"内容","folderId":1,"format":"markdown"}
```

**文档模板说明**：

| 模板 | 适用场景 | 内容结构 |
|------|---------|---------|
| 空白文档 | 通用 | 空白 |
| 会议纪要 | 会议记录 | 会议信息/议题/决议/待办 |
| 技术方案 | 技术设计 | 背景/方案/实现/风险 |
| 学习笔记 | 知识整理 | 概述/要点/示例/总结 |
| 个人日记 | 日常记录 | 日期/心情/今日事/明日计划 |
| 项目周报 | 项目汇报 | 本周完成/下周计划/风险问题 |

#### 4.2.2 Markdown 编辑器功能

**文档大纲（TOC）**：
- 编辑页右侧自动提取 H1~H6 标题生成大纲
- 点击大纲项可快速跳转到对应标题位置
- 大纲随文档内容实时更新

**双向链接**：
- 使用 `[[docId|标题]]` 语法引用其他文档
- 链接可点击跳转到目标文档
- 目标文档的"反向链接"面板显示所有引用它的文档
- 自动发现并高亮双向链接关系

**文档导出**：
- 支持导出为 **Markdown** (.md) 格式
- 支持导出为 **HTML** (.html) 格式
- 导出保留原文档格式和结构
- 操作：文档详情页 → 更多 → 导出

#### 4.2.3 编辑与版本

- 每次保存自动创建版本快照（存入 MongoDB，保留全量历史）
- 文档详情页可查看历史版本列表
- 支持回滚到任意历史版本
- **版本对比**：选择两个历史版本，查看行级 diff（新增绿色、删除红色、修改高亮）

| 操作 | API | 说明 |
|------|-----|------|
| 文档列表 | `GET /kb/api/doc/list?folderId={id}&page=1&size=20` | 按文件夹分页查询 |
| 文档详情 | `GET /kb/api/doc/{id}` | 含最新内容、字数、spaceId |
| 更新文档 | `PUT /kb/api/doc/{id}` | Body: `{title, content}` |
| 删除文档 | `DELETE /kb/api/doc/{id}` | 进回收站，30 天可恢复 |
| 收藏/取消收藏 | `PUT /kb/api/doc/{id}/star` | 切换收藏状态 |
| 移动文档 | `PUT /kb/api/doc/{id}/move` | Body: `{folderId}` |
| 导出文档 | `GET /kb/api/doc/{id}/export?format=md` | 支持 md/html 格式 |
| 版本对比 | `GET /kb/api/version/diff?versionId1={v1}&versionId2={v2}` | 返回行级 diff |

#### 4.2.4 版本管理

| 操作 | API | 说明 |
|------|-----|------|
| 版本列表 | `GET /kb/api/version/list?resourceType=doc&resourceId={id}` | 按时间倒序 |
| 版本详情 | `GET /kb/api/version/{versionId}` | 含内容快照 |
| 回滚版本 | `POST /kb/api/version/{versionId}/rollback` | 恢复到指定版本 |
| 版本对比 | `GET /kb/api/version/diff?versionId1={v1}&versionId2={v2}` | 两个版本差异对比 |

### 4.3 文件管理

#### 4.3.1 上传文件（分片上传）

1. 进入空间 → 选择文件夹
2. 点击"上传文件"或拖拽文件到上传区
3. 前端将文件分片（默认每片 5MB），逐片上传
4. 所有分片上传完成后调用合并接口
5. 合并成功后自动触发内容解析（PDF/Word/文本）

**分片上传流程**：

```bash
# 步骤1：上传分片（循环调用，partNumber 从 1 开始）
POST /kb/api/file/upload
Form: file=<分片二进制>, fileId=<文件唯一ID>, chunkNumber=<分片序号>

# 步骤2：合并分片
POST /kb/api/file/merge
Body: {"fileId":"xxx","filename":"文件.pdf","folderId":1,"totalChunks":10}
```

> **注意**：实际接口参数为 `fileId/chunkNumber`（非 `uploadId/partNumber`）。前端自动管理分片逻辑，用户无需手动操作。

**支持的文件类型**：
- 文档：PDF、Word（doc/docx）、文本（txt/md）— 自动解析内容
- 图片：jpg、png、gif、webp — 不解析内容
- 其他：可上传任意类型，但不会解析内容

**文件大小限制**：单个文件最大 200MB（Nginx `client_max_body_size 200m`）

#### 4.3.2 文件高级操作

| 操作 | API | 说明 |
|------|-----|------|
| 文件列表 | `GET /kb/api/file/list?folderId={id}&page=1&size=20` | 按文件夹分页 |
| 文件详情 | `GET /kb/api/file/{id}` | 基本信息 + 解析状态 |
| 解析状态 | `GET /kb/api/file/{id}/parse-status` | PENDING/PARSING/SUCCESS/FAILED |
| 下载文件 | `GET /kb/api/file/{id}/download-stream` | 流式下载（支持大文件） |
| 解析内容 | `GET /kb/api/file/{id}/content` | 获取解析后的文本 |
| 重新解析 | `POST /kb/api/file/{id}/reparse` | 解析失败后可重试 |
| 删除文件 | `DELETE /kb/api/file/{id}` | 进回收站 |
| 收藏文件 | `PUT /kb/api/file/{id}/star` | 切换收藏 |
| 移动文件 | `PUT /kb/api/file/{id}/move` | Body: `{folderId}` |
| 在线编辑（文本文件） | `PUT /kb/api/file/{id}/content` | 保存文本文件编辑内容 |

**文本文件在线编辑**：
- 支持格式：txt、md、json、csv、xml、html、log、yaml、ini 等文本类文件
- 操作：文件详情页 → 点击"编辑" → 修改内容 → 保存
- 保存后自动更新：MinIO 文件 + MongoDB 元数据 + MeiliSearch 索引
- 大文件（>1MB）建议下载后本地编辑

#### 4.3.3 存储桶管理（管理员）

| 操作 | API | 说明 |
|------|-----|------|
| 桶列表 | `GET /kb/api/bucket/list` | MinIO 存储桶列表 |
| 桶统计 | `GET /kb/api/bucket/{id}/stats` | 桶内对象数、总大小 |

### 4.4 网页收藏

将网页内容保存到知识库，支持离线阅读。

#### 4.4.1 收藏网页

1. 点击"新建网页收藏"
2. 输入网页 URL
3. 系统自动抓取网页正文（去除广告、导航等）
4. 保存后可随时查看，即使原网页失效也能阅读

```bash
POST /kb/api/web/collect
Body: {"url":"https://example.com/article","folderId":1,"title":"自定义标题"}
```

#### 4.4.2 网页高级操作

| 操作 | API | 说明 |
|------|-----|------|
| 网页列表 | `GET /kb/api/web/list?folderId={id}&page=1&size=20` | 按文件夹分页 |
| 网页详情 | `GET /kb/api/web/{id}` | 含抓取的正文内容 |
| 删除网页 | `DELETE /kb/api/web/{id}` | 进回收站 |
| 收藏网页 | `PUT /kb/api/web/{id}/star` | 切换收藏 |
| 移动网页 | `PUT /kb/api/web/{id}/move` | Body: `{folderId}` |
| 重新抓取 | `POST /kb/api/web/{id}/refetch` | 原网页更新后可重新抓取 |

> **注意**：网页收藏无"编辑"接口，如需修改标题/内容，请删除后重新收藏。

### 4.5 全文搜索

系统包含**两套独立的搜索体系**，服务于不同场景：

| 体系 | 面向用户 | 搜索范围 | 搜索引擎 | 入口 |
|------|---------|---------|---------|------|
| 用户侧全文搜索 | 所有用户 | 个人知识库（文件/笔记/网页） | MeiliSearch 全文检索 | `/search` 页面 |
| 知识引擎文档搜索 | 管理员 | 运维文档库（导入的 Markdown） | MySQL LIKE 匹配 | 知识引擎各页面筛选 |

#### 4.5.1 用户侧全文搜索

**入口**：顶部搜索框 或 `/search` 页

**基础搜索**：
- 支持中英文混合搜索
- 搜索范围：文档内容、文件解析内容、网页收藏正文、标题、标签
- 支持高亮显示匹配关键词（`<em>` 标签标红）
- 搜索结果按相关度排序
- 支持按资源类型筛选（全部/文件/笔记/网页）

```bash
# 全文搜索
GET /kb/api/search?q=关键词&page=1&size=20

# 可选过滤参数
GET /kb/api/search?q=关键词&type=doc&folderId=1&tagId=5&page=1&size=20
```

**参数说明**：
| 参数 | 类型 | 说明 |
|------|------|------|
| q | String | 搜索关键词（必填） |
| type | String | 资源类型过滤：doc/file/web，不传搜全部 |
| folderId | Long | 限定文件夹范围 |
| tagId | Long | 限定标签（走标签关联查询，非全文搜索） |
| page/size | int | 分页参数，默认 page=1, size=20 |

#### 4.5.2 搜索建议

在 Header 全局搜索框或搜索页输入时，自动提示匹配的文档标题：
- 输入停止 300ms 后触发搜索建议
- 下拉显示匹配的文档标题列表
- 点击建议项直接搜索该关键词
- 支持按文档标题模糊匹配

```bash

```

#### 4.5.3 索引说明

- 文档/文件/网页创建、更新、删除时自动同步到 MeiliSearch 索引
- 索引写入在事务提交后执行，避免数据回滚但索引已写入的不一致
- 当前**无手动索引重建接口**，如遇索引不一致，需联系管理员通过运维脚本处理
- **降级策略**：MeiliSearch 不可用时，搜索接口自动回退到 MySQL LIKE 查询（支持 doc 和 web 类型，file 暂不支持降级）

#### 4.5.4 知识引擎文档搜索（管理员）

**入口**：知识引擎 → 文档库（`/intel/docs`）等页面的筛选功能

知识引擎搜索针对导入的运维结构化文档，基于 MySQL 元数据匹配：
- 搜索范围：文档标题、摘要、标签、文件路径
- 筛选维度：文档类型（TABLE/PLAN/TIMELINE/GRAPH/RULE/GENERAL）、标签、分类
- 结果按更新时间倒序

```bash
POST /kb/api/intelligence/machine/search
Body: {
  "query": "Nginx",
  "docTypes": ["PLAN", "TABLE"],
  "tags": ["#Nginx"],
  "page": 1,
  "size": 20
}
```

> **注意**：知识引擎搜索当前为 MySQL LIKE 匹配，**不支持**语义搜索和向量检索。MeiliSearch 向量索引（kn_vectors）为规划中功能。

## 七、常见问题

### 7.1 浏览器证书警告

**现象**：访问 https://kb.marschat.online/kb/ 时浏览器提示"您的连接不是私密连接"或"证书无效"。

**原因**：kb.marschat.online 域名未备案，临时复用 nexus.marschat.online 的 SSL 证书，CN 不匹配。

**处理**：
- Chrome：点击"高级" → "继续前往 kb.marschat.online（不安全）"
- Firefox：点击"高级" → "接受风险并继续"
- Edge：点击"详细信息" → "继续转到此网页（不推荐）"

> 这是预期行为，不影响数据安全。后续将申请独立证书。

### 7.2 页面加载 504

**现象**：前端能打开但 API 返回 504 Gateway Timeout。

**原因**：VM (192.168.31.105) 离线，Nginx 无法连接 kb-gateway:8090。

**处理**：
1. 联系管理员检查 VM 状态
2. 管理员通过 Tailscale 后台查看 VM 在线状态
3. VM 恢复后自动恢复服务

### 7.3 上传大文件失败

**现象**：上传超过 100MB 的文件失败。

**检查项**：
- Nginx 限制：`client_max_body_size 200m`（已配置）
- 网络稳定性：分片上传依赖稳定网络
- 浏览器限制：建议使用 Chrome/Firefox 最新版

**处理**：分片上传失败可重试，已上传的分片不会重复传输。

### 7.4 搜索找不到内容

**可能原因**：
1. 文件类型不支持解析（如视频、压缩包）
2. 内容刚上传，索引尚未建立（默认 60 秒内同步）
3. 文件已删除（在回收站中，不参与搜索）

**处理**：
- 等待 1 分钟后重试
- 检查文件是否在回收站

### 7.5 分享链接打不开

**检查项**：
- 分享是否已过期
- 是否需要提取码（4 位数字）
- 资源是否已被删除（资源删除后分享失效）

### 8.4 前端部署更新

> **架构铁律**：前端静态资源部署在 **mykng-debian 本地** `/data/kb-web/`，**不部署到腾讯云2号**。腾讯云2号仅做 SSL 终结 + 纯反向代理，所有请求通过 Tailscale 转发到 mykng 本地 Nginx 处理。

```bash
# 1. 在开发机打包前端
cd d:\huliang\java\ideaworkspace\devtools\mykng\kb-web
pnpm install
pnpm build

# 2. 上传 dist/ 到 mykng-debian（不是腾讯云2号！）
scp -r dist/* root@100.93.36.113:/data/kb-web/

# 3. 创建 kb/index.html 副本（使 /kb/ 路径能找到 index.html）
ssh root@100.93.36.113 "cp /data/kb-web/index.html /data/kb-web/kb/index.html"

# 4. 验证（在 mykng-debian 本地）
curl -I http://localhost/kb/
curl -I http://localhost/kb/s/assets/
```

> **注意**：腾讯云2号上**不应**有任何 `/data/knowledge-base/web/` 目录或前端静态文件。如发现该目录，请立即清理——这是 v2 旧架构的残留，已废弃。

### 8.6 Nginx 配置位置（双层架构）

| 文件 | 位置 | 职责 |
|------|------|------|
| kb.marschat.online（腾讯云2号） | 腾讯云2号 `/etc/nginx/sites-available/kb` | **纯 SSL 终结 + 反向代理**（不存任何静态文件，所有请求转发到 mykng 本地 Nginx） |
| kb.marschat.online（mykng 本地） | mykng-debian `/etc/nginx/sites-available/kb.marschat.online` | **静态资源服务 + API 反向代理**（前端 `/data/kb-web/`，API → `127.0.0.1:8090`） |
| nexus.marschat.online | 腾讯云2号 `/etc/nginx/sites-available/nexus` | Nexus 私服（独立服务） |

**双层架构铁律**：
- 腾讯云2号 Nginx：仅做 SSL 终结 + 纯反向代理，**不存储任何静态文件**
- mykng 本地 Nginx：处理静态资源服务 + API 反向代理
- 所有服务（5 微服务 + 5 基础设施）均部署在 mykng-debian

修改任一 Nginx 配置后必须执行：

```bash
# 在对应机器上执行
nginx -t && nginx -s reload
```

### 9.2 服务职责

| 服务 | 端口 | 职责 | 接口数 |
|------|------|------|--------|
| kb-gateway | 8090 | API 网关、JWT 鉴权、路由、链路追踪 | - |
| kb-auth | 8081 | 用户登录、Token 管理、API Token | 12 |
| kb-file | 8082 | 文件上传/合并/解析、桶管理 | 13 |

| kb-ops | 8084 | 运维看板、主机/服务/端口/账密/域名/依赖/操作日志/部署记录/矛盾检测 | 47 |
| kb-intelligence | 8085 | 智能助手、知识语义搜索、实体识别、知识导入 | 12 |

| 缓存/Token 黑名单 | Redis | 高速缓存 |

### 9.4 部署架构（双层 Nginx，所有服务在 mykng）

```
公网用户 → HTTPS → 腾讯云2号 Nginx (1.117.70.30:443)
                    │ 纯 SSL 终结 + 反向代理（不存静态文件）
                    │
                    └─ 所有 /kb/* → Tailscale → mykng-debian 本地 Nginx (:80)
                                                      │
                                                      ├─ /kb/api/* → 127.0.0.1:8090 (kb-gateway)
                                                      ├─ /kb/s/*   → /data/kb-web/ (静态资源)
                                                      └─ /kb/*     → SPA 路由回退

mykng-debian (192.168.31.105 / Tailscale: 100.93.36.113)
  ├─ 本地 Nginx (:80) — 静态资源 + API 反代
  └─ Docker Compose (10 个容器)
      ├─ kb-gateway (:8090 唯一对外映射)
      ├─ 4 个业务微服务（Docker 内网）
      │   ├─ kb-auth (:8081)
      │   ├─ kb-file (:8082)
      │   ├─ kb-knowledge (:8083)
      │   └─ kb-ops (:8084)
      └─ 5 个基础设施（Docker 内网）
          ├─ MySQL 8.0 (:3306)
          ├─ Redis 7 (:6379)
          ├─ MinIO (:9000/:9001)
          ├─ MeiliSearch (:7700)
          └─ MongoDB 7 (:27017)
```
