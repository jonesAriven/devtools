## 一、文档状态机

### 1.1 状态定义

| 状态码 | 状态名 | 说明 | 数据库字段 |
|--------|--------|------|-----------|
| S1 | 草稿（DRAFT） | 新建文档初始状态 | doc.status=0, doc.deleted=0 |
| S2 | 已发布（PUBLISHED） | 文档编辑保存后 | doc.status=1, doc.deleted=0 |
| S3 | 已归档（ARCHIVED） | 归档存放 | doc.status=2, doc.deleted=0 |
| S4 | 回收站（TRASHED） | 逻辑删除 | doc.deleted=1 |
| S5 | 已恢复（RESTORED） | 从回收站恢复 | doc.deleted=0（回到 S2） |
| S6 | 已删除（DELETED） | 物理删除 | 记录物理删除 |

### 1.2 状态迁移图

```
        ┌─────────┐  publish   ┌──────────┐  archive  ┌──────────┐
        │  S1 草稿 │ ────────► │ S2 已发布 │ ────────► │ S3 已归档 │
        │         │ ◄──────── │          │ ◄──────── │          │
        └────┬────┘   edit    └────┬─────┘ unarchive └────┬─────┘
             │                     │                       │
             │ delete              │ delete                │ delete
             ▼                     ▼                       ▼
        ┌─────────────────────────────────────────────────────┐
        │                    S4 回收站                         │
        └────┬───────────────────────────────┬────────────────┘
             │ restore                       │ permanentDelete
             ▼                               ▼
        ┌──────────┐                    ┌──────────┐
        │ S5 已恢复 │                    │ S6 已删除 │
        │ (→S2)    │                    │ (终态)    │
        └──────────┘                    └──────────┘
```

### 1.3 迁移路径覆盖矩阵

| 迁移 ID | 起始状态 | 目标状态 | 触发动作 | 对应用例 ID | 覆盖状态 |

| T-DOC-01 | S1 草稿 | S2 已发布 | POST /doc 创建后首次保存 | L1-KNOW-003, L2-KNOW-004, BDD-004 | ✅ |
| T-DOC-02 | S2 已发布 | S1 草稿 | PUT /doc/{id} 重新编辑 | L1-KNOW-004, L2-KNOW-006, BDD-004 | ✅ |
| T-DOC-03 | S2 已发布 | S3 已归档 | 归档操作（业务规则） | L1-KNOW-003（扩展） | ✅ |
| T-DOC-04 | S3 已归档 | S2 已发布 | 取消归档 | L1-KNOW-003（扩展） | ✅ |
| T-DOC-05 | S1 草稿 | S4 回收站 | DELETE /doc/{id} | L2-KNOW-007, BDD-004 | ✅ |
| T-DOC-06 | S2 已发布 | S4 回收站 | DELETE /doc/{id} | L1-KNOW-011, L2-KNOW-007, L3-FLOW-002, BDD-004 | ✅ |

## 二、分享状态机

### 2.1 状态定义

| 状态码 | 状态名 | 说明 | 数据库字段 |
|--------|--------|------|-----------|
| S1 | 活跃（ACTIVE） | 分享有效，可访问 | share.expire_at > now, share.deleted=0 |
| S2 | 过期（EXPIRED） | 超过有效期 | share.expire_at <= now |
| S3 | 已撤销（REVOKED） | 创建者主动撤销 | share.deleted=1 |

### 2.2 状态迁移图

```
        ┌──────────┐  expire   ┌──────────┐

        └────┬─────┘           └──────────┘
             │ revoke
             ▼
        ┌──────────┐
        │ S3 已撤销 │
        │ (终态)    │
        └──────────┘
```

## 三、文件解析状态机

### 3.1 状态定义

| 状态码 | 状态名 | 说明 | 数据库字段 |
|--------|--------|------|-----------|
| S1 | 待解析（PENDING） | 文件合并后初始状态 | kb_file.parse_status=PENDING |
| S2 | 解析中（PROCESSING） | 异步任务开始解析 | kb_file.parse_status=PROCESSING |
| S3 | 已解析（SUCCESS） | 解析成功，文本入库 | kb_file.parse_status=SUCCESS |
| S4 | 解析失败（FAILED） | 解析异常 | kb_file.parse_status=FAILED |
| S5 | 重新解析（REPARSE→S1） | 触发重新解析回到待解析 | POST /file/{id}/reparse |

### 3.2 状态迁移图

```
        ┌──────────┐  start   ┌───────────┐  success  ┌──────────┐
        │ S1 待解析 │ ────────►│ S2 解析中  │ ────────► │ S3 已解析 │
        │          │          │           │           │ (终态)    │
        └────┬─────┘          └─────┬─────┘           └──────────┘
             │                      │ fail
             │                      ▼
             │                ┌───────────┐
             │                │ S4 解析失败 │
             │                │           │
             │                └─────┬─────┘
             │                      │ reparse
             │     reparse          │
             └──────────────────────┘
                    (S4→S1)
        reparse from S3: S3→S1 (重新解析已解析文件)
```

### 3.3 迁移路径覆盖矩阵

| 迁移 ID | 起始状态 | 目标状态 | 触发动作 | 对应用例 ID | 覆盖状态 |
|---------|---------|---------|---------|------------|---------|
| T-FILE-01 | (无) | S1 待解析 | POST /file/merge 合并分片 | L1-FILE-002, L2-FILE-002, L3-FLOW-003, BDD-005 | ✅ |
| T-FILE-02 | S1 待解析 | S2 解析中 | 异步任务拉取（自动） | L1-FILE-005（扩展） | ✅ |
| T-FILE-03 | S2 解析中 | S3 已解析 | 解析成功，写 MongoDB | L1-FILE-005, L3-FLOW-003, BDD-005 | ✅ |
| T-FILE-04 | S2 解析中 | S4 解析失败 | 解析异常（如损坏文件） | L1-FILE-006（扩展） | ✅ |
| T-FILE-05 | S1 待解析 | S4 解析失败 | 不支持的类型直接失败 | L1-FILE-006 | ✅ |
| T-FILE-06 | S4 解析失败 | S1 待解析 | POST /file/{id}/reparse | L2-FILE-005（扩展） | ✅ |
| T-FILE-07 | S3 已解析 | S1 待解析 | POST /file/{id}/reparse 重新解析 | L1-FILE-005（扩展） | ✅ |
| T-FILE-08 | S1 待解析 | S3 已解析 | 端到端：合并→解析→成功 | L3-FLOW-003, BDD-005 | ✅ |
| T-FILE-09 | S3 已解析 | S3 已解析 | GET /file/{id}/parse-status 查询（状态不变） | L2-FILE-005 | ✅ |
| T-FILE-10 | S4 解析失败 | S4 解析失败 | GET /file/{id}/parse-status 查询失败状态 | L2-FILE-005（扩展） | ✅ |
