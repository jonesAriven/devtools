## 三、提测流程

```
开发自测通过 ──► 填写提测单 ──► 提交提测邮件/工单 ──► 测试接收
      │                                              │
      ▼                                              ▼
 自测Checklist 全勾                          SIT 冒烟测试（24h 内）
                                                     │
                                              ┌──────┴──────┐
                                              ▼             ▼
                                          冒烟通过       冒烟失败
                                              │             │
                                              ▼             ▼
                                          正式测试       退回开发
```

### 3.1 SIT 冒烟测试范围

提测后 24h 内，测试团队执行 SIT 冒烟（核心流程）：
- [ ] 登录认证（POST /auth/login）
- [ ] 创建文档（POST /doc）
- [ ] 上传文件（POST /file/upload + /file/merge）
- [ ] 搜索（GET /search?q=）
- [ ] 创建分享（POST /share）
- [ ] 运维看板（GET /ops/dashboard）

冒烟 100% 通过则进入正式测试；任一失败则退回开发。

---

## 四、提测驳回条件

出现以下任一情况，测试有权驳回提测：
- 自测 Checklist 未全部打勾
- SIT 冒烟测试有失败项
- SonarQube 有阻断/严重问题
- 接口文档与代码不一致
- 数据库脚本未验证
- 提测单填写不完整
