## 三、失败用例详情

### L3-PAGE-013：分享验证页 /kb/share/non-existent-code ❌ FAIL

**失败现象**：
- 访问 `https://kb.marschat.online/kb/share/non-existent-code`
- HTTP 状态码：200（页面本身加载正常）
- 实际跳转 URL：`https://kb.marschat.online/kb/login?redirect=/kb/login`
- 预期行为：作为公开页面（`requiresAuth: false`），应显示"分享不存在"提示，**不应**重定向到登录页

**根因分析**：
- 路由守卫未对该公开分享页正确放行，或 `/kb/share/:code` 路由的 meta.requiresAuth 配置缺失
- 重定向目标 `redirect=/kb/login` 出现嵌套，疑似路由匹配优先级问题（`/kb/share/:code` 可能被通配登录拦截规则覆盖）

**影响范围**：
- 仅影响"分享不存在"提示场景，正常分享码访问流程未在本轮测试覆盖
- 不影响本次新增的 4 个页面（分享中心管理页 /kb/share 正常工作）

**复现截图**：`tests/reports/L3-PAGE-013.png`

**修复建议**：
1. 检查前端路由配置 `kb-web/src/router` 中 `/kb/share/:code` 的 `meta.requiresAuth` 是否设置为 `false`
2. 检查全局路由守卫 `beforeEach` 中对 `requiresAuth === false` 的放行逻辑
3. 检查重定向 URL 拼接逻辑，避免 `redirect=/kb/login` 嵌套

## 五、浏览器控制台错误（Top 10）

测试过程中捕获到 20 条控制台错误，主要分类如下：

### 5.1 后端 500 错误（资源不存在）
```
Failed to load resource: the server responded with a status of 500 (Internal Server Error)
Error: 文档不存在
  at ue (https://kb.marschat.online/kb/s/assets/index-Bvo_wBOm.js:9:153567)
```
- **触发场景**：访问 `/kb/doc/1`、`/kb/file/1`、`/kb/web/1` 等不存在的资源 ID
- **影响**：页面能正常加载（HTTP 200），仅后端 API 返回 500，前端有错误兜底显示
- **建议**：后端对不存在的资源应返回 404 而非 500

### 5.2 回收站日期格式化异常
```
TypeError: Cannot read properties of undefined (reading 'getFullYear')
  at g (https://kb.marschat.online/kb/s/assets/format-Dc3aGJr8.js:1:230)
  at https://kb.marschat.online/kb/s/assets/TrashVie...
```
- **触发场景**：回收站页面（/kb/trash）渲染日期字段
- **根因**：`format` 工具函数未对 `undefined` 入参做防御，回收站数据中存在 `null/undefined` 的删除时间字段
- **建议**：在 `format.js` 的 `g` 函数开头增加空值判断，返回 `'-'` 或空字符串
