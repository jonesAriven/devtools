### 4.5 PITest 变异测试

**执行命令**：`mvn -P!fast clean verify -B`（禁用 fast profile，触发 PITest）
**执行位置**：mykng-debian (100.93.36.113)
**总耗时**：8 分 42 秒（其中 PITest 5 分 7 秒）

#### 4.5.1 关键修复

**问题**：PITest 此前从未真正执行过

**根因**：kb-parent/pom.xml 的 PITest 配置仅在 `<pluginManagement>` 中声明，`<build><plugins>` 未声明 `pitest-maven`，导致子模块即使继承父 POM 也不会触发 PITest 执行

**修复**：在 [kb-auth/pom.xml](../../kb-auth/pom.xml#L137-L158) 的 `<build><plugins>` 中显式声明：

```xml
<plugin>
    <groupId>org.pitest</groupId>
    <artifactId>pitest-maven</artifactId>
</plugin>
```

**验证**：修复后重跑 `mvn -P!fast clean verify`，日志显示：
```
[INFO] Created 26 mutation test units in pre scan
[INFO] Sending 34 test classes to minion
[INFO] Calculated coverage in 27 seconds.
[INFO] Created 26 mutation test units
```

#### 4.5.5 问题分析与改进方向

**主要问题**：kb-auth 的单元测试覆盖严重不足
- 91% 的变异点（690/754）没有任何测试覆盖
- 在有覆盖的变异中，测试强度仅 50%（仅杀掉一半变异）

**改进方向**：
1. 补充 `AuthServiceImpl` 的分支测试（登录失败、Token 过期、刷新逻辑）
2. 补充 `UserServiceImpl` 的边界测试（用户不存在、状态禁用、逻辑删除）
3. 补充 `ApiTokenServiceImpl` 的权限测试（Token 校验、过期检查、最后使用时间）
4. 补充 `JwtTokenProvider` 的边界测试（Token 生成、解析、过期判断）
5. 补充 `CryptoUtil` 的加解密测试（不同输入长度、异常输入）

**预期效果**：补充上述测试后，变异得分预计可提升至 70%+，达到 SOP 阈值。
