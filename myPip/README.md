# myPip 本地Python包管理工具

## 简介

myPip 是一个本地Python包管理工具，用于在离线或网络受限环境下管理Python依赖包。它可以创建本地PyPI镜像服务器，缓存常用的Python包，并提供简单的包管理功能。

## 功能特点

- **本地PyPI镜像**: 搭建私有PyPI服务器，减少对外网的依赖
- **包缓存管理**: 自动缓存已下载的包，避免重复下载
- **批量下载**: 支持从requirements.txt批量下载依赖包
- **版本控制**: 支持指定包的版本号，确保环境一致性
- **代理支持**: 支持通过代理服务器下载包

## 系统要求

- Python 3.6+
- pip 19.0+
- 足够的磁盘空间用于存储包缓存

## 安装说明

1. 克隆或下载本仓库
2. 运行初始化脚本
3. 配置本地包存储路径

## 使用方法

### 启动本地PyPI服务器

```bash
# 启动本地PyPI服务器
python -m myPip.server start
```

### 下载包到本地缓存

```bash
# 下载单个包
python -m myPip.download flask

# 从requirements.txt下载
python -m myPip.download -r requirements.txt
```

### 从本地安装包

```bash
# 从本地缓存安装
python -m myPip.install flask
```

## 配置选项

可以通过配置文件自定义以下设置：

- 本地缓存目录
- 代理服务器设置
- 默认PyPI源
- 包过滤规则

## 常见问题

- **包下载失败**: 检查网络连接或代理设置
- **版本冲突**: 使用 `--no-deps` 选项避免依赖冲突
- **空间不足**: 使用清理命令删除不常用的包缓存

## 注意事项

- 定期更新本地缓存以获取最新的包版本
- 在生产环境中使用前，建议在测试环境验证包的完整性
- 对于大型项目，建议使用虚拟环境隔离依赖
