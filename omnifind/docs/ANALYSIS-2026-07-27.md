## 1. 项目理解

本地全能搜索工具，三层架构 + 统一路由：

- **L1 文件名层**：SQLite 存路径/名称/大小/mtime。双后端：Windows USN（纯 ctypes 读 MFT，秒级冷启动，需 SYSTEM）/ walk（跨平台 os.walk）
- **L2 全文层**：SQLite FTS5 + jieba 中文分词；抽取器插件注册表（pdf/docx/xlsx/pptx/纯文本）
- **L3 语义层**：ONNX 本地推理（bge-small-zh）+ LanceDB 向量库，chunk 级嵌入
- **QueryRouter**：统一语法（`filename:` `content:` `?语义` `all:` `re:` `ext:` `sort:`），auto 模式三层混排
- **Web**：FastAPI 127.0.0.1:8899，暗色 UI + 预览/打开/定位/设置/重建

## 2. 产品经理视角

### 做得好的
1. 查询语法对 Power User 友好（前缀+ext+sort 组合），auto 模式对小白零门槛
2. 配置驱动（scan_roots/exclude_dirs/类型表全部 yaml 化），打包默认+本地覆盖+系统级三层优先级设计合理
3. L3 范围圈定的"分叉点 2"设计（用户指定目录优先，否则按类型自动圈定+全盘安全阀）避免了向量库爆炸
4. 安全边界清晰：预览/打开/定位都要求文件必须在索引内，127.0.0.1 绑定

### 缺陷/建议
1. ⚠️ **USN 索引无文件大小**（MFT 枚举不带 size，全部存 0）→ 前端大小列空白、`sort:size` 对 USN 索引无意义。建议：build 后对命中文件批量 `GetFileAttributesEx` 补采，或后台慢任务回填
2. ⚠️ **L3 语义层从未实测过**（模型未下载即整层静默跳过）——本次修复了路径断链，链路已通，但需要跑一次 `scripts/fetch_model.py` 做真实验证
3. ⚠️ **rebuild 期间对应层搜索结果为空**（先 DELETE 再重建）——已修正 UI 文案，长期建议"建新表→切换"双缓冲
4. 语义模式在 L3 不可用时返回空结果无任何提示，建议响应里带 `l3_available` 供前端提示
5. `.xls` 预览依赖 xlrd 但未在 requirements 声明（优雅降级为不支持提示，建议补可选依赖注释）

## 3. 架构师视角

### 做得好的
1. 抽取器注册表模式（@register + PRIORITY）扩展新格式零路由改动
2. FilenameIndex 存储与后端契约分离（FilenameBackend ABC），USN/walk 可插拔
3. WAL 模式 + threading.Lock + check_same_thread=False，并发实测 160 请求零错误（234 req/s）
4. FTS5 查询用 jieba 分词 + 双引号包裹 token，特殊字符（`C++`、`(test)`、`100%`）不炸，且有 LIKE 降级
5. indexer_service 对 walk 后端有 30 分钟全量兜底（watch 未实现时）

### 缺陷/建议
1. ⚠️ **L2 upsert 每文档一次 commit**（3 SQL + fsync/篇）——全盘索引时 I/O 是瓶颈，建议批量 commit（每 500 篇）
2. ⚠️ **L1 子串搜索 LIKE %x% 全表扫**——百万级条目约 100ms 可接受，但若到千万级需考虑文件名也入 FTS5
3. ⚠️ **USN watch 删除按 name 模糊删**（`DELETE WHERE name=?`）会误删同名文件——代码已注释为已知简化，v2 需做 FRN→路径重建
4. `OmniConfig.load()` 模块级副作用（import 即读盘生成 DATA_DIR 常量），测试/多配置场景需要 monkeypatch 两处命名空间，建议依赖注入化
5. walk 后端 watch 仍是 NotImplementedError 占位（watchdog 已在依赖里，可接）

## 4. 设计师视角

### 做得好的
1. 暗色主题完成度高，亮/暗切换、系统跟随、快捷键（Ctrl+K）齐全
2. 搜索历史、层筛选标签、语法提示（? 帮助浮层）都在降低学习成本
3. 预览面板支持查找高亮、截断提示、来源标注（file_read/docx_extract 等）

### 缺陷/建议
1. ⚠️ 结果项大小列对 USN 索引恒为空（产品缺陷传导到 UI），建议空时显示 `—` 而非留白
2. snippet 高亮已修复为真高亮（原 `[ ]` 方括号裸显示）
3. 设置面板"索引统计"数字格式化好，但 L3 恒 0 时无"未启用"说明，建议灰显+提示
