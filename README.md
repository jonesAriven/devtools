# DevTools 开发工具集

这是一个开发过程中常用的工具集合，旨在提高开发效率、简化常见任务和解决开发环境问题。

## 工具列表

### 1. 二维码生成器和识别器 (QR_generator)

一个带有图形界面的二维码工具（C++ Win32 原生开发），支持：

**核心功能**：
- 文本转二维码（实时生成）
- 截屏选区识别二维码
- 上传图片识别二维码
- 多页二维码支持（压缩模式 M5 / 非压缩模式 M5R）
- 压缩模式可选（Brotli + Base45 压缩）
- 纠错等级可选（L / M / Q / H）

**截图与快捷键**：
- 全局快捷键截图（默认 Ctrl+Alt+S，可在设置中自定义或禁用）
- 截图时屏幕变暗 + 居中提示文字，拖拽选区后自动识别
- 悬浮进度窗显示多页收集进度，支持拖拽移动（位置记忆）
- 悬浮进度窗内置"截图"按钮，方便连续截图

**技术特点**：
- 静态链接 /MT，单文件发布，无运行时依赖
- ZXing C++ 解码引擎，高识别率
- 打包文件名含时间戳后缀

**已知问题**：
- 截图模式的居中提示文字样式未生效（代码已修改但未生效，待排查）
- 设置对话框（⚙按钮）点击无反应，待排查

### 2. C#版二维码生成器 (QR_generatorByC)

基于C#开发的简单易用的二维码生成工具，使用Windows Forms构建用户界面。

**功能特点**：
- 简洁直观的用户界面
- 快速生成高质量二维码
- 支持任意文本内容（网址、文本、联系方式等）
- 使用QRCoder库，生成的二维码符合标准规范

**系统要求**：Windows操作系统，.NET 6.0或更高版本

### 3. 自定义Nginx配置工具 (custNginx)

预配置的Nginx服务器配置文件，专为开发环境定制，提供TCP和HTTP代理功能。

**功能特点**：
- TCP代理：支持MySQL等数据库服务的TCP端口转发
- HTTP反向代理：支持将请求转发到不同的后端服务
- 负载均衡：内置简单的负载均衡配置示例
- 静态文件服务：可用作静态资源服务器

### 4. 增强搜索工具 (evethingPlus)

基于Everything搜索引擎的增强工具，提供更强大的文件搜索和管理功能。

**功能特点**：
- 快速搜索：继承Everything的极速搜索能力
- 增强过滤：支持更复杂的搜索条件和正则表达式
- 开发者工具集成：与常用IDE和开发工具无缝集成
- 搜索结果预览：支持文件内容预览

### 5. Maven私服管理工具 (myMaven)

用于快速部署和管理Maven私服的工具集，基于Nexus Repository Manager实现。

**功能特点**：
- 跨平台支持：同时支持Windows和Linux环境
- 智能代理：优先从常用的中央库下载依赖，并缓存到本地
- 缓存管理：支持删除缓存和备份缓存功能
- 多仓库支持：同时支持Maven中央仓库和阿里云Maven仓库

### 6. 本地Python包管理工具 (myPip)

用于在离线或网络受限环境下管理Python依赖包的工具，可创建本地PyPI镜像服务器。

**功能特点**：
- 本地PyPI镜像：搭建私有PyPI服务器，减少对外网的依赖
- 包缓存管理：自动缓存已下载的包，避免重复下载
- 批量下载：支持从requirements.txt批量下载依赖包
- 版本控制：支持指定包的版本号，确保环境一致性

### 7. 代理设置管理工具 (代理)

用于管理Windows系统代理设置的工具，主要功能是添加代理排除地址。

**功能特点**：
- 自动获取管理员权限：自动请求并获取修改系统代理设置所需的权限
- 智能添加排除地址：避免重复添加已存在的地址
- 批量添加：支持一次性添加多个排除地址
- 图形界面：提供简单的操作界面
