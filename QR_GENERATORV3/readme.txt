========== 二维码生成+截图识别工具 ==========
适配系统：Windows
核心功能：实时输入生成二维码、鼠标框选选区识别二维码、本地图片识别
打包特点：单EXE、无黑窗、无额外DLL依赖、国内源极速安装

============================================
一、清理旧冲突依赖
============================================
pip uninstall -y pyzbar

============================================
二、安装运行依赖（推荐清华镜像，国内最快）
============================================
pip install pillow qrcode opencv-python -i https://pypi.tuna.tsinghua.edu.cn/simple

备用镜像（下载慢可切换）
阿里云：
pip install pillow qrcode opencv-python -i https://mirrors.aliyun.com/pypi/simple/
中科大：
pip install pillow qrcode opencv-python -i https://pypi.mirrors.ustc.edu.cn/simple/

============================================
三、文件准备
============================================
1. 将完整源码保存为：qr_tool.py
2. 源码与打包命令在同一目录执行

============================================
四、打包生成单文件EXE命令
============================================
pyinstaller -F --noconsole qr_tool.py

参数说明：
-F        打包为独立单个exe文件
--noconsole 运行程序不弹出黑色命令行窗口

============================================
五、打包后文件位置
============================================
打包完成后自动生成文件夹：
build  临时缓存文件夹（可删除）
dist   最终成品exe存放目录
qr_tool.spec 打包配置文件（可删除）
直接进入dist文件夹双击 qr_tool.exe 即可使用

============================================
六、软件使用方法
============================================
1. 文本框输入任意文字，上方二维码实时自动刷新
2. 点击【截图识别】：全屏灰色遮罩，鼠标拖拽框选二维码区域
3. 松开鼠标自动识别，识别成功/失败文字自动填入下方输入框
4. 主窗口全程不最小化，支持多开同时使用
5. 点击【上传图片】可选择本地图片识别二维码内容

============================================
七、常见问题
============================================
1. 打包后闪退：确认已卸载pyzbar，全程使用opencv识别
2. 下载依赖超时：更换上方备用pip镜像源
3. 选区识别不准：尽量完整框住整张二维码
