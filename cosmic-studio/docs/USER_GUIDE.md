# cosmic-studio 使用说明

> COSMIC 度量表生产系统 · 版本 0.2 · 更新日期 2026-08-29

## 1. 系统概览

- **访问地址**：http://192.168.31.105:8310 （家庭局域网/手机浏览器同地址自适应）
- **初始账号**：admin / cosmic@2026（**首次登录后请到 系统管理 修改密码**）
- **一句话定位**：编写 → 门禁 → 评审 → 版本 → 导出的 COSMIC 度量表全流程生产系统；确定性规则全部系统强制拦截，LLM 只做可选的自动生成。

## 2. 角色与权限

| 角色 | 能力 |
|---|---|
| **管理员 admin** | 全部功能 + 用户管理 + 规范修改 + 覆盖导入 + 归档导入 + 删除项目 |
| **编辑 editor** | 编写（建模块/FP/子过程/编辑/差异化）+ 增量导入 + 版本快照 + 评审 |
| **只读 viewer** | 查看/门禁检查/导出下载，不可写 |

账号管理在 系统管理 → 用户管理（admin 创建，可禁用）。

## 3. 三分钟上手：手工编写一份 cosmic

1. **编写库 → 新建项目**：填需求编号（必填）+ 需求名称（必填）
2. 进入项目详情 → **新建模块**：填一/二/三级模块名（三级名禁含禁词）
3. **新建功能过程**：选模块 + 填动词开头的名称（如"新增资费标准显隐开关"）
   → 系统自动推导：F 列功能用户、E 列触发事件、按动词展开 EW/ERX 标准子过程
4. 点子过程行的 **编辑**：填数据属性（用「、」分隔，至少 3 个，建议打乱顺序）
   → 或点 FP 行的 **差异化**：一键从字段池按种子填充（可复现、防同质化）
5. **推导检查** → 有差异点 **一键修复推导列**
6. **质量门禁** → errors=0 后 **导出 xlsx** 交付

## 4. 编写库：按需求组织

- **一个需求 = 一个项目 = 一个独立编写空间**，互不可见
- 同一需求可有多个**编写副本**（列表按需求分组展示，主副本带「主」标）：
  - **复制**：从任一副本深拷贝出新副本（如 LLM 一版 + 手工一版并存）
  - **设主**：标记当前正式版本（同需求互斥）
  - **对比**：副本 vs 主副本的 FP 差异清单（共有/独有）
  - **删除**：从未打过版本快照的副本会强提示"数据不可恢复"
- 顶部搜索框：按需求编号/名称/客户名过滤

## 5. 导入与导出

### 导入（三个入口：编写库页 / 归档库页 / 项目详情页）

- **先下载导入模板**（对话框内链接）：含标准表头 + 灰色示例行 + 「填写说明」sheet（逐列要求）
- 数据从**第 5 行**起填，A-K 列有效；E 列功能用户两行格式；K 列属性用「、」禁逗号
- **增量导入**：按业务主键 upsert（模块=一二三级，FP=模块+FP 名），命中更新（子过程整体重写），不碰其他数据
- **覆盖导入**：清空目标重灌，**admin 专属**，覆盖前自动备份到服务器 /data/backups/
- 导入后建议：项目详情页跑「推导检查」+「质量门禁」，errors=0 再交付

### 导出

- 项目详情页「导出 xlsx」：标准 COSMIC 格式（A-P 列、合并规则与交付件同口径）
- 归档库每行可导出 xlsx / JSON；版本管理页可下载任意历史版本

## 6. 评审修订

1. 表格行点「**评审**」→ 录入意见（选类型：文本替换型/结构调整型/内容质疑型），意见挂载到该行
2. 顶栏「评审（N）」打开评审面板，每条意见可：
   - **去修改**：打开该行编辑框，保存后**自动生成新版本** + 意见关闭为"已手动修订"
   - **自动优化**（面板顶部按钮）：把全部待处理意见一次交给 LLM 批量修改对应行，全部通过门禁后**生成一个新版本**（版本说明列出本轮处理了哪些意见）
3. 铁律：结构调整型意见（合并/拆分/排序）AI 无权直接改，只出方案待人工确认；AI 改坏会被门禁保险丝自动回滚

## 7. 版本管理

- **何时打版本**：手动修订、AI 自动优化自动打；重要节点可手动「创建版本快照」（可写变更说明）
- 每个版本 = xlsx 文件 + sha256 指纹，不可覆盖，可下载回看
- 删除副本时无存档会强提示——先打快照再删

## 8. 质量门禁（12 类检查，errors≠0 不能交付）

F列格式 / E列格式 / EWX规范 / 子过程描述 / 数据组后缀 / 数据属性分隔符与字段数 / 禁词（FP名） / 伪字段与PII / 属性池化差异化（重复集合+Jaccard） / 同需求相似度65%（E类+CRUD兄弟豁免） / 跨库相似度85%（编写↔归档） / 字段池覆盖提醒

## 9. 规范中心（规则即数据）

- 25 条规范（编写 18 + 截图 7）全部可查可改，**保存立即生效**（无需重启）
- 常用：`min_fields_error`（属性字段数下限）、`sim_same_req`（相似度阈值）、`ewx_rules`（动词→子过程结构）
- 改坏了点「还原」回落内置默认值
- 禁词/伪字段黑名单在「规则」区单独增删

## 10. 对话式工作台（可选，需配置 LLM）

系统管理 → LLM 配置填 OpenAI 兼容端点（如 deepseek：`https://api.deepseek.com/v1` + `deepseek-chat` + key）并启用。
然后在工作台直接说："看看编写库有哪些项目"、"跑一下项目1的门禁"、"查一下资费相关的词库术语"、"导出项目2"。
未配置时功能入口仍在，点击会提示先配置。

## 11. 业务词库

从 40 个历史项目（3780 FP）提取的 6593 条业务术语，按频次排序可搜索。写 FP 名/属性时先查词库保证命名一致性（后续版本将支持自动晋升）。

GET  /api/{dim}/projects/{pid}/export/xlsx      导出

POST /api/active/projects/{pid}/versions        版本快照
POST /api/active/projects/{pid}/copy            复制副本
GET  /api/active/projects/{pid}/diff?against=N  副本 FP 对比

GET  /api/studio/specs                          规范中心

## 13. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 建 FP 报"含禁词" | FP 名含 记录/日志/导入/缓存/明细/列表/详情/效果，换个说法 |
| 导入报"字段池未收录" | 新数据组未建字段池；到规范中心放行或补池后用「差异化」 |
| 覆盖导入按钮不可选 | 需要 admin 角色 |
| 删副本弹"从未创建版本快照" | 该副本无任何存档，确认无误再删；建议先打快照 |
| 对话说"LLM 未配置" | 到 系统管理→LLM配置 填端点+模型+key 并启用 |
| 相似度错误一大片 | 同需求内 FP 名/子过程描述与已有内容太像；参考词库换命名；E 类描述是固定格式豁免不用管 |

- **已知限制**：单实例 MySQL 无冗余；LLM 真实链路待配置 key 后端到端验证；版本文件无自动清理
