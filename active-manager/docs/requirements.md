# 激活码管理系统 - 需求文档

## 1. 项目概述

### 1.1 项目背景
本项目旨在构建一个安全、可靠的激活码管理系统，用于生成和验证软件产品的激活码。系统采用非对称加密（RSA）技术保证激活码的安全性，防止激活工具被破解。

### 1.2 项目目标
- 提供激活码生成服务
- 提供激活码验证服务
- 确保激活码不可伪造和篡改
- 支持激活码有效期管理
- 记录激活码使用历史

### 1.3 安全性要求
- 激活码必须使用 RSA 非对称加密签名
- 私钥严格保密，仅用于生成激活码
- 公钥可公开，用于验证激活码
- 验证工具独立于生成服务，防止破解

## 3. 非功能需求

### 3.1 性能需求
- 激活码生成响应时间 < 100ms
- 激活码验证响应时间 < 50ms

### 3.2 可靠性需求
- 数据库数据持久化存储

- 日志记录完整，便于问题排查

### 3.3 可扩展性需求
- 支持密钥轮换机制
- 支持多种加密算法扩展
- 支持多租户部署

## 4. 接口需求

### 4.1 生成激活码接口
- **URL**: `POST /api/activation/generate`
- **请求体**:
  ```json
  {
    "serialNumber": "string (必填, 设备序列号)",
    "expireDays": "integer (可选, 有效期天数, 默认365)"
  }
  ```
- **响应体**:
  ```json
  {
    "success": "boolean",
    "message": "string",
    "activationCode": "string (激活码)",
    "expireTime": "long (过期时间戳)",
    "serialNumber": "string"
  }
  ```

### 4.2 验证激活码接口
- **URL**: `POST /api/activation/verify`
- **请求体**:
  ```json
  {
    "activationCode": "string (必填, 激活码)"
  }
  ```
- **响应体**:
  ```json
  {
    "success": "boolean",
    "message": "string",
    "serialNumber": "string (序列号)",
    "expireTime": "long (过期时间戳)",
    "expired": "boolean (是否过期)"
  }
  ```

## 5. 数据需求

### 5.1 数据库表设计
**表名**: `activation_record`

| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 主键ID |
| serial_number | VARCHAR(512) | NOT NULL, UNIQUE | 设备序列号 |
| activation_code | TEXT | NOT NULL | 激活码 |
| expire_time | BIGINT | NOT NULL | 过期时间戳(毫秒) |
| create_time | DATETIME | NOT NULL | 创建时间 |
| update_time | DATETIME | NOT NULL | 更新时间 |

### 5.2 密钥文件
- **私钥文件**: `./rsa_keys/private_key.pem` - 用于生成激活码签名
- **公钥文件**: `./rsa_keys/public_key.pem` - 用于验证激活码

---

## 6. 业务流程

### 6.1 激活码生成流程
```
客户端请求 → 验证序列号 → 查询是否已存在 → 生成RSA签名 → 保存记录 → 返回激活码
```

### 6.2 激活码验证流程
```
客户端请求 → 解析激活码 → 验证RSA签名 → 检查有效期 → 返回验证结果
```

### 6.3 离线验证流程
```
客户端 → 读取公钥 → 解析激活码 → 验证签名 → 检查有效期 → 返回结果
```

---

## 7. 安全约束

1. **私钥保护**: 私钥文件仅存储在服务端安全位置，禁止对外泄露
2. **签名算法**: 使用 SHA256withRSA 算法确保签名安全性
3. **激活码格式**: 使用 Base64URL 编码，便于传输和存储
4. **防止重放攻击**: 通过有效期机制防止激活码重复使用超过有效期

---

## 8. 验收标准

### 8.1 功能验收
- 激活码生成成功，签名验证通过
- 重复序列号检测正确
- 有效期设置生效
- 过期激活码验证失败

### 8.2 安全验收
- 使用伪造激活码验证失败
- 修改激活码内容后验证失败
- 私钥泄露前无法伪造激活码

### 8.3 性能验收
- 生成接口响应时间 < 100ms
- 验证接口响应时间 < 50ms
