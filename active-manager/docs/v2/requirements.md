# 激活码管理系统 V2 - 需求文档

## 1. 产品概述

### 1.1 产品定位

激活码管理系统是一套**软件授权保护解决方案**，由三个独立工程协作完成：

| 工程 | 定位 | 一句话描述 |
|------|------|-----------|
| activation-code-server | 激活码服务端 | 生成并管理激活码，提供管理后台 |
| activation-code-verifier | 激活码验证工具 | 提供API供工具软件接入，验证授权、生成唯一序列号 |
| QRCodeTool | 二维码扫描工具（示例） | 只做工具功能，需要验证就接入verifier |

### 1.2 核心业务目标

- 为软件产品提供**离线可用**的授权验证机制
- 激活码**不可伪造、不可篡改、不可跨设备使用**
- 验证工具可**嵌入多种语言**开发的软件（当前C#，后续可扩展）
- 管理员可通过后台**全流程管控**激活码的生成、查询、稽核
- 工具软件**零改动业务代码**即可接入激活验证

### 1.3 用户角色

| 角色 | 使用场景 |
|------|---------|
| 管理员 | 在管理后台生成激活码、查看记录、查看稽核日志、解析工具 |
| 终端用户 | 打开工具软件 → 弹窗显示唯一序列号 → 发给管理员获取激活码 → 粘贴激活码完成激活 |

## 2. 功能需求

### 2.1 激活码服务端（activation-code-server）

#### 2.1.1 激活码生成

| 需求编号 | 功能点 | 描述 | 优先级 |
|---------|--------|------|--------|
| SRV-001 | 加密序列号解密 | 接收客户端加密的唯一序列号，自动解密出初始序列号、设备ID、机器码 | 高 |
| SRV-002 | 激活码生成 | 根据序列号+设备ID+有效期，RSA私钥签名生成激活码 | 高 |
| SRV-003 | 有效期分钟级精度 | 有效期单位为分钟，支持5分钟到1年 | 高 |
| SRV-004 | 重复检测 | 同一序列号已存在未过期激活码时拒绝重复生成 | 高 |
| SRV-005 | 记录保存 | 激活码记录保存到数据库，包含初始序列号、机器码等完整信息 | 高 |

#### 2.1.2 激活码验证

| 需求编号 | 功能点 | 描述 | 优先级 |
|---------|--------|------|--------|
| SRV-006 | 签名验证 | RSA公钥验证激活码签名有效性 | 高 |
| SRV-007 | 有效期检查 | 检查激活码是否过期 | 高 |
| SRV-008 | 设备验证 | 验证激活码是否绑定当前设备 | 高 |
| SRV-009 | 首次激活时间 | 验证成功时记录首次激活时间 | 中 |

#### 2.1.3 管理后台

| 需求编号 | 功能点 | 描述 | 优先级 |
|---------|--------|------|--------|
| SRV-010 | 激活码管理工具标签 | 生成激活码+验证激活码，支持快捷有效期选择 | 高 |
| SRV-011 | 激活码记录标签 | 查看所有激活码记录，支持搜索和状态筛选 | 高 |
| SRV-012 | 操作日志标签 | 查看稽核日志，按事件类型筛选 | 高 |
| SRV-013 | 解析工具标签 | 解析激活码内容、解析序列号信息 | 中 |
| SRV-014 | 独立生成页面 | /tool.html 提供简洁的激活码生成页面，有效期最长30天 | 中 |

#### 2.1.4 稽核日志

| 需求编号 | 功能点 | 描述 | 优先级 |
|---------|--------|------|--------|
| SRV-015 | 生成事件记录 | 记录激活码生成事件（GENERATE / GENERATE_DUPLICATE） | 高 |
| SRV-016 | 验证事件记录 | 记录验证结果（VERIFY_SUCCESS / VERIFY_FAIL） | 高 |
| SRV-017 | 过期事件记录 | 记录激活码过期事件（EXPIRED） | 高 |
| SRV-018 | 设备不匹配记录 | 记录设备不匹配事件（DEVICE_MISMATCH） | 高 |
| SRV-019 | 客户端IP记录 | 每次操作记录客户端IP地址 | 中 |

### 2.2 激活码验证工具（activation-code-verifier）

#### 2.2.1 核心验证API

| 需求编号 | 功能点 | 描述 | 优先级 |
|---------|--------|------|--------|
| VER-001 | 一站式启动保护 | LaunchWithProtection：加载缓存→验证→弹窗→定时检查，一行代码接入 | 高 |
| VER-002 | 激活码验证 | RSA公钥验证激活码签名，检查有效期和设备绑定 | 高 |
| VER-003 | 设备绑定验证 | 自动采集设备指纹，验证激活码是否绑定当前设备 | 高 |
| VER-004 | 定时过期检查 | 运行时每60秒检查激活码是否过期，过期后自动退出 | 高 |

#### 2.2.2 唯一序列号

| 需求编号 | 功能点 | 描述 | 优先级 |
|---------|--------|------|--------|
| VER-005 | 生成唯一序列号 | 加密编码：初始序列号|设备ID|机器码 → XOR加密 → Base64 | 高 |
| VER-006 | 解析唯一序列号 | 反向解密唯一序列号，提取初始序列号、设备ID、机器码 | 高 |

#### 2.2.3 安全防护

| 需求编号 | 功能点 | 描述 | 优先级 |
|---------|--------|------|--------|
| VER-007 | 反调试检测 | 检测调试器附加，检测到时静默失败 | 高 |
| VER-008 | 时间篡改防护 | 基于单调时钟检测系统时间被回拨 | 高 |
| VER-009 | 激活码加密存储 | AES-256加密存储到本地，绑定设备ID，防止文件复制 | 高 |
| VER-010 | 公钥加密保护 | 公钥分段多key XOR加密存储，使用后内存清零 | 高 |
| VER-011 | 错误信息脱敏 | 验证失败不返回详细原因，防止信息泄露 | 高 |
| VER-012 | 内存安全清理 | 敏感数据使用后立即清零，防止内存dump | 高 |

### 2.3 工具软件接入（以QRCodeTool为例）

| 需求编号 | 功能点 | 描述 | 优先级 |
|---------|--------|------|--------|
| TOOL-001 | 零改动业务代码 | Form1.cs等业务代码不需要任何修改 | 高 |
| TOOL-002 | 一行代码接入 | Program.cs只需调用LaunchWithProtection即可 | 高 |
| TOOL-003 | 激活弹窗 | 未激活时自动弹出激活对话框，显示唯一序列号 | 高 |
| TOOL-004 | 过期自动退出 | 运行时检测到过期，弹窗提示后自动退出 | 高 |

## 3. 非功能需求

### 3.1 安全性

- RSA 2048位非对称加密，私钥仅服务端持有
- 激活码不可伪造（无私钥无法生成有效签名）
- 激活码不可篡改（任何修改导致签名验证失败）
- 激活码不可跨设备使用（绑定设备指纹）
- 激活码文件不可复制到其他设备（AES加密+设备ID派生密钥）
- 验证工具不可被调试分析（反调试检测+静默失败）
- 系统时间回拨无法延长有效期（单调时钟防护）

### 3.2 可扩展性

- 验证工具后续可提供多种语言版本（不止C#），供不同语言开发的工具软件接入
- 新工具软件接入时，只需引用verifier对应语言的库，调用API即可
- 服务端不关心客户端是什么语言，只关心加密序列号的解密和激活码的生成/验证

### 3.3 离线可用

- 客户端验证完全离线，不需要联网
- 服务端故障不影响已激活的工具软件使用
- 激活码一旦生成，验证不依赖服务端

## 4. 业务流程

### 4.1 激活流程

```
终端用户打开工具软件
        ↓
verifier自动生成唯一序列号（加密值）
        ↓
弹窗显示唯一序列号，用户复制给管理员
        ↓
管理员在后台粘贴序列号 → 服务端自动解密出设备ID+机器码
        ↓
管理员设置有效期 → 生成激活码（RSA签名）
        ↓
管理员将激活码发给终端用户
        ↓
用户粘贴激活码 → verifier验证（签名+设备+有效期）
        ↓
验证通过 → 激活码AES加密存储到本地 → 软件正常运行
        ↓
运行时每60秒定时检查有效期
```

### 4.2 过期流程

```
定时检查发现激活码过期
        ↓
安全删除本地激活码文件（覆写零后删除）
        ↓
弹窗提示"授权已失效"
        ↓
程序退出（退出码1002）
```

## 5. 数据需求

### 5.1 激活码记录表（activation_record）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| serial_number | VARCHAR(512) | 唯一序列号（初始序列号-机器码） |
| device_id | VARCHAR(128) | 设备ID（SHA256指纹） |
| activation_code | TEXT | 激活码 |
| expire_time | BIGINT | 过期时间戳（毫秒） |
| activated_time | DATETIME | 首次激活时间 |
| expire_minutes | INT | 有效期分钟数 |
| initial_serial | VARCHAR(256) | 初始序列号（软件标识） |
| machine_code | VARCHAR(256) | 机器码（MAC地址格式化） |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

### 5.2 稽核日志表（activation_log）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| record_id | BIGINT | 关联记录ID |
| serial_number | VARCHAR(512) | 序列号 |
| device_id | VARCHAR(128) | 设备ID |
| event_type | VARCHAR(32) | 事件类型 |
| event_message | VARCHAR(512) | 事件描述 |
| client_ip | VARCHAR(64) | 客户端IP |
| create_time | DATETIME | 创建时间 |

### 5.3 事件类型枚举

| 事件类型 | 说明 |
|---------|------|
| GENERATE | 激活码生成成功 |
| GENERATE_DUPLICATE | 重复生成被拒绝 |
| VERIFY_SUCCESS | 验证成功 |
| VERIFY_FAIL | 验证失败 |
| EXPIRED | 激活码已过期 |
| DEVICE_MISMATCH | 设备不匹配 |
