# EverythingPlus 增强搜索工具

## 简介

EverythingPlus 是基于 Everything 搜索引擎的增强工具，提供了更强大的文件搜索和管理功能，帮助开发人员快速定位和管理项目文件。

## 功能特点

- **快速搜索**: 继承 Everything 的极速搜索能力，瞬间找到所需文件
- **增强过滤**: 支持更复杂的搜索条件和正则表达式
- **开发者工具集成**: 与常用IDE和开发工具无缝集成
- **搜索结果预览**: 支持文件内容预览，无需打开即可查看文件内容
- **自定义操作**: 可配置常用操作，如在编辑器中打开、复制路径等

## 系统要求

- Windows 操作系统
- 已安装 Everything 搜索工具
- .NET Framework 4.5 或更高版本

## 安装说明

1. 确保已安装 Everything 搜索工具
2. 下载 EverythingPlus 安装包
3. 运行安装程序，按照向导完成安装
4. 首次运行时，配置与 Everything 的连接

## 使用方法

### 基本搜索

1. 启动 EverythingPlus
2. 在搜索框中输入关键词
3. 使用过滤器缩小搜索范围（如：文件类型、修改日期等）

### 开发者功能

- **代码搜索**: 使用 `code:关键词` 语法搜索代码内容
- **项目过滤**: 使用 `proj:项目名` 限定在特定项目中搜索
- **文件类型过滤**: 使用 `ext:扩展名` 限定文件类型

## 自定义配置

可通过配置文件自定义以下内容：

- 搜索结果显示字段
- 快捷键绑定
- 外部工具集成
- 搜索规则和过滤器

## 常见问题

- **无法连接到 Everything**: 确保 Everything 已启动并启用了 HTTP 服务器
- **搜索结果不完整**: 检查 Everything 索引设置是否正确
- **性能问题**: 尝试减少搜索范围或优化过滤条件
