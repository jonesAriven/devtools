## 系统设计

### 组件架构（官方能力要点）

SiYuan 是开源（AGPL）隐私优先的块级笔记系统：

- **块级（block）编辑模型**
  - 一切内容皆块，支持双向链接、关系图/反链面板。
  - SQL 式块查询、属性与标签体系。
- **技术栈**
  - Go 内核（HTTP 服务，默认端口 6806，自带访问鉴权）。
  - Electron 桌面端 + Vue 前端。
  - 服务端模式（docker 自托管）提供 Web 访问。
- **数据形态**
  - 工作空间目录（.siyuan）内以 JSON 文件 + assets 附件存储。
  - 天然适合文件级备份与同步。
- **导出能力**：Markdown、PDF、图片、公众号排版导出等。

### 我们的集成设计（预期角色）

- **实例角色**
  - mykng 上 docker 自托管服务端。
  - 作为个人/小范围私密笔记与项目知识沉淀库，公网经 `note.marschat.online` 随处访问。
- **与哪些系统连接**
  - 上游：腾讯云2号 nginx。
  - 数据完全本地（工作空间卷），不依赖商业云。
  - 与记忆提炼面板（memory.marschat.online）同属知识类但独立——SiYuan 为人工笔记，memory-panel 为自动提炼。
- **为什么选它**
  - 块级 + 双链适合长期知识沉淀。
  - 数据落本机文件，隐私与可迁移性好。
- **关键配置思路**（恢复部署时参考）
  - docker 镜像 `siyuan`（官方 b3log/siyuan 系）映射 6806。
  - 工作空间目录挂载到宿主卷持久化。
  - 首次启动设置访问口令（入 Vaultwarden）。
