系统设计

组件架构（官方能力要点）

SiYuan 是开源（AGPL）隐私优先的块级笔记系统：

  • 块级（block）编辑模型
  • 一切内容皆块，支持双向链接、关系图/反链面板。
  • SQL 式块查询、属性与标签体系。
  • 技术栈
  • Go 内核（HTTP 服务，默认端口 6806，自带访问鉴权）。
  • Electron 桌面端 + Vue 前端。
  • 服务端模式（docker 自托管）提供 Web 访问。
  • 数据形态
  • 工作空间目录（.siyuan）内以 JSON 文件 + assets 附件存储。
  • 天然适合文件级备份与同步。
  • 导出能力：Markdown、PDF、图片、公众号排版导出等。
